# 전선소환전 / Frontline Summoners — 통합 전체 기획서 v1.2

문서 상태: **1차 완성 범위 상세 정본**  
최상위 결정: `docs/CANONICAL.md`  
성장/모집/진화: `docs/GROWTH_RECRUITMENT_DESIGN.md`  
스테이지/SPECIAL/협동: `docs/STAGE_SYSTEM_DESIGN.md`  
개별 제작 사양: `docs/content-wiki/`  
실제 구현 상태: `docs/IMPLEMENTATION_STATUS.md`

> 이 문서는 게임 전체의 목적, 1차 완성 범위, 공통 시스템 규칙을 사람이 한 번에 읽을 수 있게 통합한다. 캐릭터 한 명의 정확한 형태별 HP/attack frame, 적 한 종의 기준 스탯, 스테이지 하나의 spawn timeline처럼 수시로 조정되는 제작 세부는 콘텐츠 위키를 단일 정본으로 사용한다. 실행 데이터가 문서와 다르면 실행값을 조용히 정답으로 취급하지 않는다.

---

# 1. 게임 한 줄 정의

**서로 다른 실루엣·비용·사거리·역할을 가진 캐릭터를 모아 10칸 덱을 만들고, 실시간 보급과 생산 타이밍을 운영하며 1차원 전선을 밀어 상대 거점을 파괴하는 브라우저 기반 횡스크롤 소환 전략 게임.**

플레이어가 반복해서 판단해야 하는 것은 다음이다.

- 지금 저비용 전열을 추가할지 고비용 핵심 유닛을 위해 기다릴지
- 보급소를 강화해 장기 경제를 키울지 당장 병력을 생산할지
- 현재 적의 사거리·선딜·공격주기에 맞춰 전선을 어디에 형성할지
- 10칸 안에 벽, 러셔, 광역, 장거리, 특정 속성 대항을 어떻게 배치할지
- 거점 병기와 생산 쿨다운을 언제 맞물릴지

싱글 플레이만으로 핵심 성장과 본편을 완주할 수 있어야 하며 같은 결정론적 전투 코어 위에서 2인 PvE 협동과 PvP가 동작한다.

# 2. 1차 완성의 경계

1차 완성은 **냥코 대전쟁의 본능에 대응하는 후반 성장축 직전까지의 밀도**를 목표로 한다. 플레이 리듬과 성장 구조는 참고하되 명칭, 캐릭터, 스토리, 아트, 수치를 복제하지 않는다.

1차 완성에 포함한다.

- 메인 4장 × 20 = 80스테이지
- 스토리 캐릭터 10종
- 공통 모집 C/B/A 15종
- 초기 모집 3시리즈, 각 S 5명 + SS 정확히 1명
- 기본 Lv1~50와 장별 상한 해제
- +레벨
- 1/2/3형태 진화와 이전 형태 재선택
- 속성/전투 태그/상태효과/특수 공격범위
- 편성/성장/모집/도감
- 상시/주기/이벤트 SPECIAL
- 기록 SPECIAL `끝없는 전선`, `보스 러시`
- 최초 도전부터 무료 2배속 + 해당 스테이지 정상 클리어 후 무료 3배속
- 소탕권
- 대부분 메인/SPECIAL의 2인 협동
- 친구/초대/빠른 통신
- PvP 일반/랭킹/친선
- MMR/티어/랭킹/보상
- 게스트/로그인/저장/이전/삭제

1차에서 억지로 만들지 않는다.

- 본능 대응 후반 성장 시스템
- 난이도 9~12를 채우기 위한 수치 뻥튀기
- 에너지/스태미나
- 누적 모집 천장/직접 선택권
- 무작위 품질 보물 파밍
- 캐릭터별 액티브 버튼 난립
- PvP 전용 필수 성장재화
- 놓치면 정상 성능이 영구 손실되는 FOMO

# 3. 세계관·톤·시각 정체성

- 판타지 약 40%, 괴상함/유머/예상 밖 소재 약 60%.
- 사람, 괴수, 식물, 언데드, 기계, 부유체, 구조물형, 비정상 생물 등 폭넓은 체형을 사용한다.
- 동일 인간형에 색/갑옷만 바꿔 캐릭터 수를 늘리지 않는다.
- 작은 전투 화면에서도 실루엣만 보고 주요 유닛을 구별할 수 있어야 한다.
- 진화는 단순 색 변경이 아니라 실루엣, 장비, 공격 방식, 모션이 실제로 변할 수 있다.
- UI는 지휘소/전선을 모티프로 깃발, 문장, 리본, 금속, 목재, 양피지 등을 사용하되 장식보다 가독성을 우선한다.

# 4. 문서 권위와 상태

의도 정본 순서:

1. `CANONICAL.md`
2. 이 통합 기획서
3. 관련 시스템 정밀 문서
4. 해당 콘텐츠 위키의 상세 페이지

실제 `content/`, schema, code, test는 위 설계를 구현한 결과다.

위키 상태:

- `CONCEPT`: 아이디어 수준, 구현 시작 금지
- `DESIGN_TARGET`: 구현 가능한 목표값, 플레이테스트 전
- `TESTED`: 자동검증+실제 플레이 확인
- `LOCKED`: 현재 릴리스 기준 정본
- `REWORK`: 현재 구현/초안을 재설계해야 함
- `DEPRECATED`: 역사 자료, 신규 구현 금지

`DESIGN_TARGET` 숫자는 테스트 후 바뀔 수 있다. `LOCKED`와 실행값이 다르면 구현 불일치다.

# 5. 전투 코어

- simulation 30 tick/s.
- 렌더는 60fps 이상 보간 가능.
- 판정은 1D X축, Y는 시각 연출용.
- 싱글과 권위 멀티 서버가 같은 sim 코어를 사용한다.
- 필요 난수는 seed 기반 결정적 PRNG.

기본 처리 순서:

1. 확정 입력
2. 자원/쿨다운/상태 타이머
3. 예약 스폰
4. 이동
5. 탐색/공격 상태 전환
6. 해당 tick hit event 수집
7. 피해/효과 일괄 적용
8. 자연 KB/강제이동/사망
9. 제거/승패
10. 결정성 상태 갱신

동일 frame 공격 결과가 배열 순서에 따라 달라지면 안 된다.

# 6. 공격·사거리·KB

공격 상태:

`이동 → anticipation/선딜 → hit frame → follow-through/후딜 → 재탐색`

- 공격 시작 시 목표는 트리거일 뿐이며 실제 hit frame에 유효 범위를 다시 판정한다.
- standingRange와 attackMin/attackMax를 분리한다.
- 사각지대, 전후방 타격, 멀티히트, 특이한 인형/반사 위치 공격을 허용한다.
- 멀티히트는 각 hit의 실제 피해와 시각 contact를 1:1로 맞춘다.
- 자연 KB와 강제이동을 별도 상태로 처리한다.
- HP≤0 즉시 전투 대상으로서 사망하고 death animation은 판정을 지연시키지 않는다.

캐릭터별 contact frame 목표는 `ANIMATION_CONTACT_FRAME_TARGETS.md`가 담당한다.

# 8. 속성과 전투 태그

1차 속성:

- `NEUTRAL`
- `BEAST`
- `UNDEAD`
- `NATURE`
- `ARCANE`
- `DEMON`
- `MACHINE`
- `ANOMALY`

기본은 1속성이고 개념이 명확하면 최대 2속성 후보.

속성은 전역 가위바위보가 아니다. 일반 공격은 정상 피해를 주며 특정 유닛의 대항 능력이 속성을 참조한다.

핵심 전투 태그:

- `ARMORED`
- `FLOATING`
- `GIANT`
- `BOSS`
- `STRUCTURE`
- `SUMMON`
- `SWARM`

**부유 태그 공식 표기는 `FLOATING` 하나다. `FLYING`은 사용하지 않는다.**

태그는 두 번째 전역 상성표가 아니다.

# 9. 전투 경제

전투 자원은 `보급` 하나.

- 생산과 보급소 강화가 같은 보급을 경쟁한다.
- 초반부터 보급이 넘쳐 모든 버튼을 연타하는 구조 금지.
- 반대로 기다리는 시간이 전투 대부분이 되지 않게 한다.

제1장 보급소 DESIGN_TARGET:

| Lv | 수입/초 | 최대 보급 | 강화비 |
| --- | ---: | ---: | ---: |
| 1 | 12 | 1000 | - |
| 2 | 20 | 1400 | 160 |
| 3 | 30 | 1900 | 260 |
| 4 | 42 | 2500 | 390 |
| 5 | 56 | 3200 | 560 |
| 6 | 72 | 4000 | 760 |
| 7 | 90 | 5000 | 1000 |
| 8 | 110 | 6200 | 1300 |

뒤 장은 비싼 캐릭터와 긴 전투를 다루므로 스테이지 시작 보급과 tempo를 점진적으로 높일 수 있다.

적 처치 보급은 전투가 완전히 마르는 것을 막되 웨이브를 잡을수록 경제가 폭발하는 구조가 되지 않게 한다.

---

# 10. 재생산

- 캐릭터/형태마다 기본 재생산 시간을 가진다.
- 영구 보상과 향후 modifier를 적용한 뒤 최종 하한을 clamp한다.
- **최종 최소 재생산 = 60F = 2초.**
- 벽/협동/PvP에서 0.x초 무한 생산이 되지 않는다.

---

# 11. 거점과 거점 병기

- 양 끝에 아군/적 거점.
- 상대 거점 HP 0이 기본 승리조건.
- 거점 HP는 전투를 의미 없이 늘이지 않게 설계한다.
- 전투당 거점 병기 1종 장착을 기본으로 한다.
- 캐릭터 액티브 스킬을 남발하는 대신 생산·경제·병기 타이밍이 직접 조작의 중심이다.

병기별 수치/업그레이드는 별도 시스템 위키에서 관리한다.

---

# 12. 스토리 캐릭터

스토리 캐릭터는 모집 희귀도를 갖지 않는다.

- `acquisitionClass = STORY`
- `rarity = null`
- 모집 저희귀의 하위 등급이 아니다.
- 후반에도 비용/역할/형태에 따라 사용 가치가 있어야 한다.

초기 10종:

1. 징집병 — 저비용 물량
2. 방벽기사 — 순수 벽
3. 수렵창병 — 긴 근접/BEAST 대항
4. 결투검사 — 빠른 단일 DPS
5. 청창대 — 중거리 전열
6. 전투마도사 — 안정 광역
7. 화염술사 — 느린 광역 한방
8. 왕실기사 — 고비용 전열 AREA
9. 이단주술사 — 장거리 사각
10. 공허현자 — 초고비용 결정타

정확한 F1/F2/F3 스탯은 `STORY_ROSTER_V1_COMBAT_SPECS.md`를 따른다.

# 13. 모집 희귀도와 시리즈

모집 희귀도:

`C / B / A / S / SS`

- C/B/A는 대체로 시리즈 공통 풀.
- S/SS는 시리즈 전용.
- **시리즈당 SS는 정확히 1명.**
- 초기 시리즈는 S 5명씩으로 시작.
- 희귀도는 비용/전투력 서열이 아니다.

초기 3시리즈:

1. `성휘의 기사단` — 미소녀·판타지 영웅
2. `태고의 거수` — 괴수·이형 생물
3. `제로 엣지` — 강화인간·기계·드론·SF 검단

시리즈 간 SS 실루엣은 `천체 여왕 / 움직이는 산 / 무인 부유 검단`처럼 확실히 분리한다.

# 14. 모집 규칙

사용하지 않는다.

- 10연 A 보장
- 30연 S 보장
- 60연 SS 보장
- 100연 직접 선택
- 누적 pity
- selection credit

현재 확률 DESIGN_TARGET:

- C 42.0%
- B 32.0%
- A 22.7%
- S 3.0%
- SS 0.3%

고희귀 확률은 낮을 수 있지만 모집 재화를 후하게 공급하고 시리즈 복각을 보장하는 방향이다.

연출:

- C/B 빠른 결과
- A 작은 강조
- S 시리즈 문장/컷인
- SS 시리즈별 고유 최고 연출
- 본 연출은 스킵 가능

# 15. 기본 레벨

장별 상한:

- 시작 Lv10
- 1장 완료 → Lv20
- 2장 → Lv30
- 3장 → Lv40
- 4장 → Lv50

기본 레벨은 HP/공격 중심으로 강하게 오른다.

현재 앵커 DESIGN_TARGET:

- Lv1 ×1.00
- Lv10 ×1.90
- Lv20 ×3.25
- Lv30 ×5.00
- Lv40 ×7.25
- Lv50 ×10.00

사거리, 이속, 비용, 재생산, KB, 공격 방식은 기본 레벨 때문에 자동 증가하지 않는다.

# 16. +레벨과 중복

1차 +레벨 상한 후보: +50.

현재 DESIGN_TARGET:

```text
plusMultiplier = 1 + 0.02 × plusLevel
```

Lv50+50은 Lv1 기준 HP/공격 ×20 목표.

- 같은 캐릭터 중복 직접 +1 = 최고 효율.
- 중복을 공용 +재화로 분해 가능.
- 공용 재화를 다른 캐릭터에 사용 가능.
- 교차 전환은 직접 중복보다 명확히 낮은 효율.
- Base Lv50만으로도 정상 완성 성능이어야 한다.

세부 분해량/+1 비용은 `PROGRESSION_NUMERICAL_TARGETS.md`를 따른다.

# 17. 골드 성장과 진화재료

현재 Lv1→50 한 캐릭터의 기본 레벨 골드 누적 DESIGN_TARGET은 약 222,230.

진화:

- F1/F2/F3
- 소유권/Lv/+Lv 공유
- 이전 형태 무료 재선택 기본
- 3형태가 상위호환일 필요 없음
- 비용/재생산/사거리/이속/KB/공격 방식/대항 능력이 달라질 수 있음

상대 재료 체급:

- STORY/C 약 ×1
- B 약 ×1.5
- A 약 ×2.2
- S 약 ×3.2~3.5
- SS 약 ×4~5

8개 속성별 재료를 각각 만들어 재화 종류를 폭증시키지 않는다.

# 18. 편성

- 솔로/1v1: 10칸.
- 협동/2v2: 플레이어당 5칸, 팀 10칸.
- 한 플레이어의 동일 캐릭터 중복 슬롯 금지.
- 미획득 캐릭터는 편성 목록에 표시하지 않는다.
- PC drag & drop.
- 모바일 long press + drag.
- 클릭/탭 추가는 보조 입력.

필터:

- 전체/스토리/C/B/A/S/SS
- 속성 대항
- 역할
- 비용/사거리
- 기본 Lv/+Lv
- 형태
- 최근/즐겨찾기

# 20. 메인 캠페인

1차 본편 4장 × 20 = 80.

# 23. 정상 클리어, 2배속, 소탕

# 25. 보상 충전

일부 주기 SPECIAL은 입장 횟수가 아니라 **고효율 반복 보상 횟수**를 충전으로 관리한다.

- 입장 무제한
- 충전이 있으면 charged reward
- 충전 0이어도 플레이 가능
- 0이면 depleted reward
- FIRST_CLEAR는 충전과 별도
- 충전은 상한까지 누적되어 하루 접속 강제를 완화

짧은 특정 시간만 열려 놓치면 큰 손해를 보는 게릴라 방식은 사용하지 않는다.

# 28. 2인 PvE 협동

대부분 메인/SPECIAL에서 솔로 또는 협동을 선택할 수 있다.

- A 5칸 + B 5칸 = 팀 10칸
- 개인 보급
- 개인 보급소
- 개인 생산 cooldown
- 공유 기지/전장/승패/거점 병기

협동 첫 클리어도 정상 진행이다.

적 2배 강화 금지. 출발 후보:

- HP ×1.15~1.30
- ATK ×1.05~1.15
- 적 거점 HP ×1.10~1.20

기본적으로 사거리, 이속, 공격주기, KB, 적 수, spawn timing, pattern은 바꾸지 않는다.

동일 캐릭터를 두 플레이어가 각각 편성하는 것은 허용 후보이며 벽/상태/초장거리 중복을 TESTED 후 잠근다.
