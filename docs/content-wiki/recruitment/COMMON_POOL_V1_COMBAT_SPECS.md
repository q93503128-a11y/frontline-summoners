# 역할 중복 검사

- C 벽은 방벽기사/RX-Ω보다 싸고 약하다.
- C 투석수는 고급 초장거리보다 저렴한 입문 후열이다.
- B 이끼골렘은 바르가보다 공격적이고 덜 극단적이다.
- A 유리등대지기는 S 미레이유/아크 레일러와 같은 초장거리군이지만 단일/비용/형태 trade-off로 공존한다.
- A 운석차는 고르무와 달리 공성 공격이 본체이고 생존은 낮다.
- A 거울길잡이는 순수 DPS보다 범위 구조가 가치다.

# LOCKED 전 필수 검증

- C/B/A 중 최소 절반 이상이 Lv50 후반 덱에서도 특정 용도를 가질 것
- 높은 희귀도가 낮은 희귀도보다 모든 수치에서 우위가 아닐 것
- 공통 풀 15종의 실루엣이 서로 구별될 것
- 초기 3시리즈 S/SS 18종과 역할 중복 비교표 작성
- 협동 동일 캐릭터 2중 편성 확인
- PvP 표준화에서 저비용 벽/초장거리 교착 확인
