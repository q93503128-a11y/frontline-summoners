# 초기 모집 시리즈 01~03 상세 초안

상태: `DESIGN_TARGET`  
상위 규칙: `docs/CANONICAL.md`, `docs/GROWTH_RECRUITMENT_DESIGN.md`

초기 1차 완성판은 공통 C/B/A 풀 + 서로 시각 언어가 크게 다른 3개 모집 시리즈를 사용한다. 각 시리즈는 S 5명으로 시작하고 **SS는 정확히 1명**만 둔다. S/SS의 최종 콘셉트와 아트는 실제 구현 전 별도 검수를 거친다.

---

# SERIES 01 — 성휘의 기사단

## 시리즈 방향

- 미소녀/판타지 영웅 중심.
- 동일 체형 + 갑옷 색상만 바꾸는 반복 금지.
- 무기 크기, 키, 자세, 체형, 실루엣, 공격 방식이 크게 달라야 한다.
- 판타지 40 / 개성 60의 게임 톤에 맞게 정통 기사만이 아니라 성녀, 인형사, 유리궁 사수 등 역할을 섞는다.

## S1 — 에르시아, 백은의 창

- 키가 크고 긴 은발 포니테일.
- 본인 키보다 훨씬 긴 은빛 랜스.
- 전열 바로 뒤에서 긴 창끝으로 싸우는 정석형 S.
- 긴 근접 사거리 / 단일 고효율 / 비교적 낮은 생산비.
- 특수능력은 적고 순수 사거리·공격 효율이 장점.
- 3형태에서는 랜스가 기병창 수준으로 커지고 장비 실루엣이 더 길어진다.

## S2 — 리에나, 불량 성녀

- 작은 체구 + 거대한 성물 철퇴.
- 성녀 이미지와 거친 태도의 대비.
- 중거리 범위 공격 / 높은 단발 피해 / 높은 KB.
- 언데드·악마 계열 대항 후보.
- 2형태에서 성물에 균열, 3형태에서는 부서진 성물을 사슬로 휘두르는 방향.

## S3 — 미레이유, 유리궁의 사수

- 풍성한 드레스 + 초대형 수정 활.
- 초장거리 / 긴 선딜 / 높은 한 방 / 명확한 사각지대.
- 제대로 보호했을 때 강력한 후열 포격형.
- 3형태는 활 자체가 복합 수정 구조로 확장되지만 캐릭터 체형은 과하게 커지지 않는다.

## S4 — 네리아, 흑장미 기사

- 한쪽 팔/다리만 중장갑인 비대칭 검은 갑옷.
- 거대한 한손검.
- 높은 HP / 짧은 사거리 / 준수한 공격.
- 특수능력 최소화, 깡스탯 전열형 S.
- 고희귀도라도 복잡한 능력이 필수라는 인상을 깨는 역할.

## S5 — 토토리아, 마도인형사

- 작은 소녀 + 본체보다 큰 전투 인형.
- 실제 공격 판정이 앞쪽 인형 위치에서 발생하는 특이 범위형.
- 중거리 / 광역 / 느린 재생산.
- 3형태에서 인형이 본체보다 훨씬 거대해져 실루엣 중심이 인형으로 이동.

## SS — 아르셀리아, 별을 두른 여왕

- 이 시리즈의 유일 SS.
- 긴 망토 안쪽이 밤하늘처럼 보이고 등 뒤의 별 모양 마법 구조체가 공전.
- 작은 화면에서도 일반 인간형과 확실히 구분되는 천체 실루엣.
- 고비용 중~장거리 / 다단 공격 / 첫 타와 마지막 타의 범위 차이.
- 강하지만 재생산이 길고 죽었을 때 손실이 큼.
- 만능 면역/만능 대항으로 만들지 않는다.
- 1형태 왕녀 → 2형태 여왕 → 3형태 인간과 천체현상의 경계가 흐려지는 방향.
- 최종 콘셉트/외형은 사용자 검수 후 확정.

# SERIES 02 — 태고의 거수

## 시리즈 방향

- 괴수, 고대 생물, 이형 생물 중심.
- 인간형 없이도 한 시리즈가 성립할 수 있다는 것을 보여준다.
- 용 색놀이가 아니라 골격/다리 수/이동 방식/몸 비율 자체가 모두 달라야 한다.

## S1 — 돌등껍질 바르가

- 등에 바위산 같은 돌기층이 솟은 네발 괴수.
- 초고HP / 매우 느림 / 짧은 사거리 / 비교적 저렴.
- 공격은 평범하고 몸 자체가 벽 역할.

## S2 — 꼬리칼날 지르카

- 작은 몸 + 몸길이의 세 배에 가까운 낫형 꼬리.
- 매우 빠른 이동 / 빠른 공격 / 낮은 체력 / 넓은 전방 범위.
- 러셔 역할.

## S3 — 풍선포자 모구

- 둥근 거대 균류 생물, 다리가 거의 없고 부유 이동.
- 느린 부유형 / 광역 포자 공격 / 낮은 직접 피해.
- Slow/Weaken 계열 보조 역할 후보.
- 3형태에서 작은 포자 생물이 군락처럼 달라붙는다.

## S4 — 천공턱 가르도

- 몸의 절반 이상이 거대한 턱 구조.
- 네발로 기어 다니며 상부 턱이 크게 벌어진다.
- 중거리 / 긴 선딜 / 매우 높은 단발 피해 / 넓은 물기 판정.
- 빗나가면 손해가 큰 고위험 한방형.

## S5 — 수정벌레 크리크

- 육족 절지형 + 등에 투명 수정 기둥.
- 낮은 HP / 긴 사거리 / 수정 투사체 연속 멀티히트.
- 기계/중갑 대상 전문화 후보.

## SS — 세계등짐 고르무

- 이 시리즈의 유일 SS.
- 등에 산과 폐허가 자라난 초대형 육족 괴수.
- 다른 캐릭터보다 확연히 크지만 실제 전투 가시성을 가리지 않을 상한을 둔다.
- 매우 높은 생산비 / 매우 느림 / 엄청난 HP / 높은 공격 / 긴 재생산.
- 특수능력 덩어리보다 `움직이는 요새`라는 존재감이 핵심.
- 3형태에서 등에 작은 성채와 숲이 완성되는 방향 후보.
- 최종 콘셉트/외형은 사용자 검수 후 확정.

# SERIES 03 — 제로 엣지

## 시리즈 방향

- 최첨단 전투 기술, 강화인간, 전투 로봇, 드론, 무인 병기, SF 검단.
- 전원을 사이버 미소녀로 만들지 않는다.
- 기계 구조와 이동 방식의 차이로 실루엣을 구분한다.

## S1 — K-17 절단자

- 인간인지 기계인지 애매한 얇은 휴머노이드.
- 양팔 자체가 긴 에너지 블레이드.
- 빠른 이동 / 빠른 공격 / 짧은 사거리 / 안정적인 근접 DPS.
- 단순하고 강한 근접형.

## S2 — 아크 레일러

- 다리가 없는 부유식 병기.
- 몸 중앙 대부분이 하나의 거대한 레일건.
- 초장거리 / 극단적으로 긴 선딜 / 높은 한 발 / 높은 비용 / 명확한 사각지대.

## S3 — NANA-04

- 소형 인간형 오퍼레이터 + 독립 드론 4기.
- 본체 공격은 약하고 드론이 순차 멀티히트.
- 안정적인 중~장거리 후열 DPS.
- 인간형이지만 드론 군집이 실루엣 중심이 되게 한다.

## S4 — 방벽기 RX-Ω

- 상체 대부분이 거대한 방패이고 작은 다리로 걷는 전투 로봇.
- 높은 HP / 거의 없는 공격 / 낮은 생산비의 고등급 벽.
- 재생산 2초 하한을 악용하지 않도록 기본 쿨은 별도 조정.

## S5 — 크로노 블레이드 하운드

- 머리가 거의 없는 네발 전투기계.
- 등에서 여러 칼날이 펼쳐진다.
- 빠른 이동 / 접근 후 고속 연타 / 공격 뒤 짧은 정지.
- 고위험 러셔.

## SS — 오버레이・아스트라

- 이 시리즈의 유일 SS.
- 인간형이 아니라 거대한 무인 부유 전투 프레임.
- 중앙 코어 주변에 칼날형 독립 모듈 6~8개가 회전.
- 고비용 중거리 / 부유 블레이드 순차 멀티히트 → 마지막 강타.
- 단순 포병이 아니라 모듈 정렬/베기 구조가 전투 정체성.
- 방어까지 만능으로 만들지 않고 긴 재생산으로 손실 리스크 유지.
- 3형태에서는 중앙 몸집보다 부유 모듈 구조가 복잡해지는 방향.
- 이름은 가칭이며 최종 콘셉트/외형은 사용자 검수 후 확정.

# 역할 분포 점검

초기 15 S는 가능한 한 같은 역할에 몰리지 않는다.

- 정석 긴 근접: 에르시아
- 중거리 한방/대항: 리에나
- 초장거리 포격: 미레이유
- 깡스탯 전열: 네리아
- 특이 판정 광역: 토토리아
- 초고HP 벽: 바르가
- 러셔: 지르카
- 상태 보조: 모구
- 고위험 한방: 가르도
- 멀티히트 후열: 크리크
- 빠른 근접 DPS: K-17
- 초장거리 레일건: 아크 레일러
- 안정 멀티히트: NANA-04
- 저비용 벽: RX-Ω
- 고위험 기계 러셔: 하운드

SS 3명은 `천체 여왕 / 움직이는 산 / 무인 부유 검단`으로 실루엣과 세계관 언어가 서로 완전히 다르게 간다.
