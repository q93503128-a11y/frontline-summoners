# 공통 모집 C/B/A 풀 v1

상태: `DESIGN_TARGET`

초기 3개 모집 시리즈는 이 공통 C/B/A 풀을 공유한다. 업데이트마다 저희귀를 대량 추가하지 않고, 필요한 역할이나 시각군이 비었을 때만 소수 보충한다.

초기 목표는 **C 5 / B 5 / A 5 = 15명**이다. S/SS와 달리 시리즈 전용이 아니며 서로 다른 세계관 출신의 용병/괴물/기계/마법 생물이 섞여도 된다.

희귀도 의미:

- C: 이해가 빠르고 기본 역할이 명료함. 후반에도 비용/재생산/극단 스탯으로 가치 유지.
- B: 명확한 전문성과 trade-off가 추가됨.
- A: 공격 구조/사거리/효과/형태가 더 독특한 경우가 많음.
- 이것은 전투력 서열이 아니다.

# C

## C1 — 순무기수

- 속성: NATURE 또는 NEUTRAL+NATURE 후보
- 역할: 저비용 빠른 러셔/전선 보충
- 외형: 커다란 순무를 말처럼 타고 다니는 작은 농부 기사.
- 핵심: 빠르게 전선에 도착하지만 체력/공격은 낮다.
- 2형태: 절임순무 기수 — 더 튼튼하고 느려지는 방향.
- 3형태: 왕순무 돌격대 — 비용/재생산이 늘고 몸집이 커지는 공격형.
- 기존 프로토타입의 `순무기수` 콘셉트가 있다면 상세 역할을 새 정본에 맞춰 회수 가능.

## C2 — 양철방패 시종

- 속성: NEUTRAL
- 태그: ARMORED
- 역할: 매우 싼 보조 벽
- 외형: 몸보다 큰 찌그러진 양철 방패 뒤에 거의 숨은 작은 시종.
- 핵심: 방벽기사보다 훨씬 약하지만 더 싸고 빠르게 빈틈을 메운다.
- 2형태: 냄비뚜껑 근위.
- 3형태: 양철성벽대 — 재생산 하한을 악용하지 않는 선에서 탱킹 효율 강화.

## C3 — 목동 투석수

- 속성: NEUTRAL
- 역할: 싼 장거리 단일
- 외형: 작은 체구, 매우 긴 가죽 투석끈, 양털 망토.
- 핵심: 값싼 후열이지만 선딜이 길고 투사체 한 발 의존도가 높다.
- 2형태: 산등성이 투석수 — 사거리 증가/사각 후보.
- 3형태: 거석 투석꾼 — 느린 대형 단발로 전환 후보.

## C4 — 종껍질 게

- 속성: BEAST
- 태그: ARMORED
- 역할: 느린 저비용 중거리 범위
- 외형: 등에 작은 종 모양 껍데기를 진 게. 집게로 치는 대신 종을 몸으로 울려 충격파 발생.
- 핵심: DPS는 낮지만 좁은 범위로 물량 정리.
- 2형태: 대종게 — 더 느리고 튼튼.
- 3형태: 종탑게 — 사거리/범위가 늘지만 비용 증가.

## C5 — 등불나방

- 속성: BEAST+ARCANE 후보
- 태그: FLOATING
- 역할: 빠른 후열 교란/낮은 체력
- 외형: 커다란 등불 같은 배를 가진 나방 생물.
- 핵심: 이동이 빠르고 공격도 가볍지만 쉽게 죽는다.
- 2형태: 유도등나방 — 속성 대항 보조 후보.
- 3형태: 월광등나방 — 부유 군집형 외형, 멀티히트 후보.

# B

## B1 — 등불마녀

- 속성: ARCANE 후보
- 역할: 중거리 지속 광역
- 외형: 빗자루 대신 살아 있는 커다란 등불을 끌고 다니는 마녀.
- 핵심: 공격 때 등불 안의 불씨가 여러 적을 핥듯 번짐.
- 2형태: 푸른등 마녀 — 공격주기/상태효과 방향.
- 3형태: 밤길 인도자 — 범위/보조 특화.
- 기존 프로토타입 콘셉트가 있다면 새 속성/형태 체계로 재작성.

## B2 — 태엽오리기사

- 속성: MACHINE
- 역할: 중저가 안정 전열 DPS
- 외형: 태엽을 등에 단 오리 모양 기계기사, 짧은 검과 둥근 투구.
- 핵심: 일정한 공격주기와 적당한 생존.
- 2형태: 장갑오리기사 — 느리지만 튼튼.
- 3형태: 폭주 태엽오리 — 더 빠른 이동/공격 대신 생존 감소.

## B3 — 관짝 장사꾼

- 속성: UNDEAD 또는 NEUTRAL+UNDEAD 후보
- 역할: 느린 중거리 한방/사망 연출형
- 외형: 등에 세로로 관을 멘 수상한 상인. 공격 시 관뚜껑이 열리며 팔/망령이 튀어나옴.
- 핵심: 긴 선딜, 높은 단일 피해.
- 2형태: 검은 장의사 — 언데드 대항/저항 후보.
- 3형태: 떠도는 영구차 — STRUCTURE 느낌의 이동형으로 역할 변화 가능.

## B4 — 이끼골렘

- 속성: NATURE
- 태그: GIANT 후보
- 역할: 중비용 탱커/느린 범위
- 외형: 돌보다 식물과 나무뿌리 비율이 높은 둔중한 골렘.
- 핵심: 느리지만 안정적으로 전선 유지. 방벽기사와 달리 실제 범위 피해가 있음.
- 2형태: 고목골렘 — HP 중심.
- 3형태: 이동정원 — 더 긴 공격주기 대신 넓은 범위.

## B5 — 먹물까마귀

- 속성: BEAST+ARCANE 후보
- 태그: FLOATING
- 역할: 장거리 약화 보조
- 외형: 까마귀 여러 마리가 하나의 검은 먹물 망토처럼 뭉친 군집체.
- 핵심: 직접 화력은 낮지만 Weaken 후보.
- 2형태: 먹구름 까마귀 — 범위 증가.
- 3형태: 검은 필경사 — 공격 방식이 먹물 표식을 남기는 형태 후보.

# A

## A1 — 유리등대지기

- 속성: NEUTRAL
- 역할: 초장거리 단일 포격 / 큰 사각
- 외형: 등에 작은 유리 등대 구조물을 지고 걷는 키 큰 인물.
- 핵심: 빛을 모아 매우 멀리 한 발을 발사. 적이 붙으면 거의 무력.
- 2형태: 백광 등대지기 — 더 긴 사거리/선딜.
- 3형태: 움직이는 등대 — STRUCTURE 태그 후보, 비용/사거리 극단화.

## A2 — 뼈북 악단장

- 속성: UNDEAD
- 역할: 중거리 범위/리듬형 멀티히트
- 외형: 몸통보다 큰 뼈북과 여러 개의 작은 팔.
- 핵심: 일정 박자에 3연타. hit frame 간격 때문에 KB/생존과 상호작용이 독특함.
- 2형태: 장송 악단장 — 범위 강화.
- 3형태: 백골 대행진 — 공격주기는 길어지고 한 사이클 타격 수 증가 후보.

## A3 — 접지 않은 종이용

- 속성: ARCANE
- 태그: FLOATING
- 역할: 중거리 넓은 범위 / 낮은 HP
- 외형: 거대한 종이 한 장이 접히며 용 형상을 유지하는 생물.
- 핵심: 공격 때 몸을 펼쳐 넓은 종이 칼날 파동을 보냄.
- 2형태: 천마리 종이용 — 작은 종이 조각 멀티히트.
- 3형태: 서고를 삼킨 용 — 더 크고 느린 광역 한방.

## A4 — 고철 운석차

- 속성: MACHINE
- 태그: STRUCTURE 후보
- 역할: 초고비용 근~중거리 공성/광역
- 외형: 바퀴 달린 거대한 투석기와 기계 생물이 합쳐진 형태.
- 핵심: 비싸지만 한 발이 매우 크고 거점/대형 적 압박에 강함.
- 2형태: 강철 운석차 — 공격력/HP 강화.
- 3형태: 궤도 낙하포 — 사거리/사각이 크게 바뀌는 포격형 후보.

## A5 — 거울길잡이

- 속성: ARCANE
- 역할: 특이 공격범위 / 전후방 타격 후보
- 외형: 얼굴 대신 작은 둥근 거울을 들고, 등 뒤에 길쭉한 거울 조각 여러 개가 떠다님.
- 핵심: 직접 앞을 때리기보다 반사된 공격이 일정 거리 뒤/앞에 생성되는 변칙형.
- 2형태: 파경술사 — 공격 위치가 더 멀어짐.
- 3형태: 천면경 — 다중 반사 멀티히트 후보.

# 공통 풀 역할 검증

C는 물량, 보조벽, 싼 장거리, 느린 범위, 빠른 부유 교란을 담당한다.

B는 안정 광역, 기계 전열, 한방, 탱커, 약화 보조로 전문성이 증가한다.

A는 초장거리, 리듬 멀티히트, 특이 부유 광역, 공성, 반사 공격범위처럼 공격 구조 자체가 더 독특하다.

어느 캐릭터도 `A라서 C보다 무조건 강하다`는 구조로 만들지 않는다. 비용/재생산/사거리/역할이 달라 실제 덱에서 공존하게 한다.
