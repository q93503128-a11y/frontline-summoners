# 1차 메인 4장 / 80스테이지 설계 지도

상태: `DESIGN_TARGET`

1차 완성은 메인 4장 × 20스테이지 = 80스테이지다. 난이도 9~12를 채우기 위해 억지 고난도를 만들지 않으며, 4장 최종전까지 최대 8 정도를 목표로 한다.

공통 규칙:

- ST01~02는 새 계정 학습 때문에 솔로 전용 가능.
- 이후 대부분 `SOLO_OR_COOP`.
- 협동 첫 클리어도 정상 진행/보상 인정.
- 영구 보상은 같은 효과 반복을 허용한다.
- 이동속도/배치한도 영구 보상은 없음.
- 각 장 ST20: 레벨 상한 해제 + 추가 보상.

# 제1장 — 뒤집힌 국경

## 장 목표

- 게임의 기본 문법 완성: 보급, 생산, 벽, 후열, 사거리, KB, 재생산, 보급소 투자.
- 속성: NEUTRAL 중심 → BEAST 첫 도입.
- 복잡한 상태이상보다 전선과 경제를 먼저 학습.
- 권장 기본 레벨: Lv1~10.
- 난이도 범위: 1~6.
- 완료: Lv20 상한 해제.

## 신규 적군 핵심군

- 약탈병: 기준 근접.
- 달림개: 빠른 BEAST 러셔.
- 냄비방패: 느린 저공격 고HP.
- 긴목창잡이: 전열 뒤 중거리 찌르기.
- 유리봉 사수: 긴 사거리/사각.
- 철퇴 난동꾼: 느린 큰 범위 한방.
- 굴렁통 멧돼지: BEAST 중량 돌격형.
- 깃발지기: 주변 적을 직접 강화하지 않더라도 스폰 조합의 중심이 되는 정예병.

보스 후보:

- 황금가면 사령술사: 장거리 범위 보스.
- 철문장군: 고HP 근거리 범위 보스.

# 제2장 — 뒤틀린 숲

## 장 목표

- 속성과 대항 캐릭터의 실제 의미를 학습.
- NATURE / UNDEAD 도입.
- Slow, Weaken 등 상태효과를 소수 적부터 읽기 쉽게 소개.
- 부활/사망 연계는 후반부 특정 적에만 사용.
- 권장 레벨: Lv12~20.
- 난이도 범위: 3~7.
- 완료: Lv30 상한 해제.

## 신규 적군 핵심군

- 이끼멧돼지: BEAST+NATURE, 높은 질량의 전열.
- 우산버섯: NATURE, 짧은 광역 포자.
- 덩굴기수: NATURE 중거리.
- 씨앗포대: NATURE 장거리 저HP.
- 뼈바퀴: UNDEAD 빠른 돌진.
- 관짝벌레: UNDEAD 고HP 저속.
- 묘지종지기: UNDEAD 중거리 범위.
- 되살아난 기사: UNDEAD+ARMORED, 한 번만 약한 부활 후보.

보스 후보:

- 뿌리과부: 거대한 이동 식물, 여러 공격 거리.
- 종 없는 장의왕: 관/종을 합친 UNDEAD 보스, 느린 광역과 부활 연계.

# 제3장 — 마도도시 세라페

## 장 목표

- ARCANE / DEMON 도입.
- 초장거리, 사각지대, 멀티히트, 전후방 공격 등 공격 범위 문법 심화.
- 플레이어가 `무조건 긴 사거리 = 강함`이 아님을 이해하게 한다.
- 권장 레벨: Lv22~30.
- 난이도 범위: 4~7.
- 완료: Lv40 상한 해제.

## 신규 적군 핵심군

- 유리눈 마도체: ARCANE, 안정 중거리.
- 주문먹는 벌레: ARCANE, 빠른 근접/마법 대항군 압박.
- 떠다니는 서고: ARCANE+FLOATING, 긴 사거리/사각.
- 잉크마귀: DEMON, 짧은 범위 다단.
- 사슬악마: DEMON, 높은 KB/강제이동 후보.
- 계약집행관: DEMON+ARMORED, 고HP 전열.
- 마도포대: ARCANE+STRUCTURE, 초장거리 고정 포격.
- 찢어진 거울수: ARCANE+DEMON 후보, 앞/뒤 분산 공격.

# 제4장 — 기어 제국의 균열

## 장 목표

- MACHINE / ANOMALY 도입.
- 지금까지의 전선/속성/사거리/상태/멀티히트를 종합한다.
- 최종 장이라고 숫자만 비정상적으로 올리지 않고, 적 구성과 타이밍으로 난도를 만든다.
- 권장 레벨: Lv32~40, 후반에는 Lv40 근접.
- 난이도 범위: 5~8.
- 완료: Lv50 상한 해제, 1차 기본 성장 완주.

## 신규 적군 핵심군

- 톱니새: MACHINE+FLOATING, 빠른 저HP.
- 자력거미: MACHINE, 중거리/전선 끌기 또는 Push 후보.
- 레일벌레: MACHINE, 긴 직선 포격/큰 사각.
- 용광로 골렘: MACHINE+ARMORED, 느린 고HP 범위.
- 접힌 병사: ANOMALY, 이동/공격 실루엣이 비정상적인 근접.
- 오류덩어리: ANOMALY, 멀티히트/불규칙 외형이지만 simulation은 결정론적.
- 공허렌즈: ANOMALY+FLOATING, 장거리 범위.
- 융합기병: MACHINE+ANOMALY, 후반 정예.

보스 후보:

- 기어황제의 이동왕좌: MACHINE+STRUCTURE+GIANT, 이동 성채형.
- 공허엔진 제로: MACHINE+ANOMALY+BOSS, 1차 메인 최종보스.

# 장별 최종 보상 추가 알파 후보

- 1장: 골드 + 모집재화 + 모집/편성 기능 완전 개방.
- 2장: 진화재료 대량 + 주기 SPECIAL 상위 단계 해금.
- 3장: 3형태 관련 핵심 SPECIAL/재료 접근 확대.
- 4장: 1차 엔딩, Lv50, 고급 SPECIAL/랭킹 시즌 정식 진입 조건 후보.

정확한 기능 해금 시점은 UI 흐름과 실제 구현 상태를 보고 조정한다.

# 다음 단계

이 파일은 80스테이지의 학습곡선 지도다. 실제 구현 전 각 스테이지를 `stages/main/chapter-XX/` 개별 페이지 또는 장별 상세표로 내려 다음을 확정한다.

- 정확한 enemy ID
- atTick/트리거/반복웨이브
- 거점 HP/맵 길이/시작 보급
- 권장 level/form/+level
- 첫/반복 보상 수치
- 협동 스케일
- 예상 클리어 시간
- 시뮬레이션/사람 테스트 결과
