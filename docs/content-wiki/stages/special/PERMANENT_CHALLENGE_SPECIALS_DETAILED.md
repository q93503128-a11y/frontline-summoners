목적: 메인과 다른 전투 조합/보스/속성 집중전을 제공하되, 특정 S/SS 소유를 강제하지 않는다. 대부분 `SOLO_OR_COOP`, 첫 클리어 보상 중심. 반복 보상은 주기 재화 SPECIAL보다 낮다.

공통:

- 첫 클리어 1×
- 재클리어 1×/2×
- 소탕 가능(이미 클리어한 단계)
- 보상 충전 없음
- 협동 기본 HP ×1.20 / 공격 ×1.08~1.10 / 기지 ×1.12
- 내부 단계 순차 해금

# 상시 SPECIAL 반복 보상 원칙

- 첫 클리어 보상은 큼.
- 반복 보상은 메인보다 약간 좋거나 비슷하되 주기 재화전 charged보다 낮음.
- 상시 보스를 최고의 골드/재화 파밍법으로 만들지 않음.
- 소탕으로 반복 보상 획득 가능.

# LOCKED 전 검증

- 모든 단계가 스토리+공통풀로 클리어 가능
- 특정 시리즈 S/SS 필수 없음
- 같은 보스의 색변경/배율 재탕이 아님
- 협동에서 보스 상태잠금 없음
- 난이도8이 실제로 1차 성장축에서 가능한가
- 반복보상이 주기 SPECIAL 경제를 침범하지 않는가
