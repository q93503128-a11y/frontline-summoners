# E1 끝없는 전선

systemId: `record_endless_front`  
정책: SOLO_ONLY  
소탕: 불가  
2배속: 기록 공정성을 위해 1× 고정 기본  
입장 제한: 없음

## 목표

계정의 덱/성장/운용을 장기 전선에서 시험하는 개인 기록 모드. 반복 파밍이 아니라 최고 생존시간 갱신이 목적.

## 기본 전장

- mapLength: 2600
- playerBaseHp: 일반 메인보다 높은 고정값 후보 8000
- 적 기지: 파괴 불가/화면 밖 생성원 또는 무한 HP
- startingSupply: 300
- worker start Lv1, max Lv8
- 승리 없음
- 플레이어 거점 파괴 시 종료

## 난이도 상승 구조

시간 `t`분에 따라 다음을 단계적으로 올린다.

- 적 base magnification
- 웨이브 간격
- 정예 적 해금
- 보스 출현

단순 선형 HP 증가만 사용하지 않는다.

### 0~2분

- 1~2장 일반 적 중심.
- magnification 0.8~1.0.
- 기본 경제 안정화 구간.

### 2~4분

- 2장 적/상태 추가.
- magnification 1.0~1.15.
- 3분 경계에 뿌리과부 0.55× 후보.

### 4~6분

- 3장 적 추가.
- 장거리/사각/러셔 혼합.
- magnification 1.15~1.30.
- 5분 경계에 대마도장 0.55×.

### 6~8분

- 4장 MACHINE/ANOMALY 도입.
- magnification 1.30~1.50.
- 7분에 이동왕좌 0.55×.

### 8~10분

- 전 장 정예 조합.
- magnification 1.45~1.70.
- 웨이브 간격 약 10~15% 단축.
- 9분에 벨자르 또는 특수 보스 0.65×.

### 10분 이후

난도가 가속.

- 2분마다 magnification 추가 상승.
- 정예 동시 조합 증가.
- 보스 간격 2~3분.
- 화면 엔티티 수 상한을 넘기지 않도록 웨이브 수보다 체급/조합을 우선.

목표 체감:

- 중반 계정: 4~7분
- 1차 완성 후반 계정: 7~12분
- 매우 강한/숙련 계정: 12분 이상 도전
- 30분 이상 방치가 일반적이지 않음

## 기록

저장:

- bestTimeMs
- bestReachedMinute
- 사용 덱 snapshot 후보
- 날짜/빌드

보상:

- 새로운 정수 분 경계 최초 돌파 때 1회.
- 예: 6:42 → 9:17이면 7/8/9분 보상.

1~5분:
- 골드/소탕권/일반 재료

6~10분:
- 모집재화/+재화/고급 재료

11분 이상:
- 재화 + 장식/칭호 비중 증가
- 성장재화가 무한히 커지지 않게 상한 또는 완만한 보상곡선

같은 기록 이하 반복 지급 없음.

## 공정성

- 외부 seed RNG로 쉬운/어려운 판이 갈리지 않음.
- 시즌별 적 순서를 바꿀 경우 모든 사용자에게 동일 규칙.
- 기록 패치로 밸런스가 크게 바뀌면 기록 시즌/버전을 구분.

## 보스 사이 지원군

보스 자체 패턴 학습이 목적이므로 일반 메인보다 보조군은 적게 사용.

- 보스당 0~2회 지원군
- 해당 보스 원래 장의 대표 적 사용
- 다음 보스 정비구간에는 이전 지원군이 남아 있다면 제거하지 않고 전투 결과를 유지하는 후보. 테스트 후 결정.

## 기록

- 최고 격파 보스 번호
- 같은 번호 내 최단/생존 상태는 보조기록 후보
- 최초 N번째 보스 격파 보상

보상 예:

- 1/2: 골드
- 3/4: 진화재료
- 5/6: 모집재화/+재화
- 7/8: 고급 재료 + 칭호
- 전체 완료: 프로필 훈장 + 대형 1회 보상

반복 파밍 보상 없음 또는 극소량.

## 실패

플레이어 기지 파괴 시 즉시 종료. 이전까지 새로 깬 기록/구간 보상은 저장.

## 난이도 표시

기록 모드 자체에 단일 `난이도 8` 같은 숫자를 붙이기보다 각 보스 구간에 예상 난이도/권장 진행을 표시할 수 있다.

# 이벤트 복각 규칙

- 이벤트 progress/first clear 기록은 계정에 유지.
- 복각 시 기존 첫 클리어 보상을 다시 주지 않음.
- 새로운 스테이지가 추가되면 해당 신규 보상만 가능.
- 이벤트 캐릭터가 있다면 이전 획득자도 중복/+레벨 활용 경로를 가져야 함.
- 기간 종료 직전 접속을 강제하는 랭킹성 이벤트 보상은 별도 설계 없이 넣지 않음.

# 기록전 완료 기준

끝없는 전선:
- 분 경계 보상 중복 없음
- 재시작/앱 종료로 기록 복제 없음
- 10분 이상에서 서버/클라이언트 엔티티 안정

보스 러시:
- 보스 전환 중 쿨/보급 상태 정확히 유지
- 이미 받은 구간 보상 중복 없음
- 보스 트리거 누락 없음
- 특정 보스에서 무한 교착 없음

두 기록전이 충분히 완성되기 전 세 번째 기록 모드를 추가하지 않는다.
