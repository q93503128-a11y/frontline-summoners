# 성장·+레벨·진화 수치 상세 목표

상태: `DESIGN_TARGET`  
상위: `docs/GROWTH_RECRUITMENT_DESIGN.md`

이 문서는 1차 완성에서 실제 경제/밸런스 시뮬레이션을 돌릴 수 있도록 기본 레벨, +레벨, 골드 비용, 중복 분해, 진화재료의 수치 목표를 정의한다. 모두 테스트 전 목표값이며 실제 플레이 결과에 따라 조정한다.

---

# 1. 기본 레벨 스탯 배율

Lv1 형태 기준 HP/공격에 같은 기본 레벨 배율을 적용한다.

앵커:

| Lv | 배율 |
| ---: | ---: |
| 1 | ×1.00 |
| 10 | ×1.90 |
| 20 | ×3.25 |
| 30 | ×5.00 |
| 40 | ×7.25 |
| 50 | ×10.00 |

앵커 사이 레벨은 **선형 보간 후 내부 소수값을 유지하고 최종 스탯에서 반올림**하는 것을 기본 후보로 한다.

예:

- Lv15 = Lv10~20 사이 50% → ×2.575
- Lv35 = Lv30~40 사이 50% → ×6.125

목적:

- 초반 레벨업도 눈에 띄게 강함.
- Lv50까지 꾸준히 성장 체감.
- 사거리/비용/이속/재생산 같은 정체성 수치는 자동 성장하지 않음.

---

# 2. +레벨 배율

+레벨은 기본 레벨 배율 위에 곱한다.

```text
plusMultiplier = 1 + 0.02 × plusLevel
finalStat = round(formLv1Stat × baseLevelMultiplier × plusMultiplier)
```

예:

| 상태 | 최종 배율 |
| --- | ---: |
| Lv10 +0 | ×1.90 |
| Lv10 +10 | ×2.28 |
| Lv20 +20 | ×4.55 |
| Lv30 +30 | ×8.00 |
| Lv40 +40 | ×13.05 |
| Lv50 +50 | ×20.00 |

장점:

- +1은 어느 진행도에서도 현재 기본 HP/공격의 약 2% 증가.
- +50은 Base Lv50 대비 정확히 2배.
- 낮은 기본 레벨에서 +레벨이 절대 배율 +0.2씩 붙는 구조보다 초반 파괴력이 덜함.

1차 +상한 후보: +50.

---

# 3. 레벨 적용 대상

기본:

- HP: 기본 Lv × +Lv 적용
- 기본 공격: 기본 Lv × +Lv 적용

고정:

- 비용
- 재생산
- 이동속도
- standingRange
- attackMin/Max
- KB 횟수
- 공격주기
- 상태효과 확률/시간

형태가 바뀌면 각 형태 Lv1 기준 스탯이 바뀌며 같은 성장배율을 적용한다.

# 5. 레벨업 UX

- 1레벨씩 강화
- 5레벨/상한까지 일괄 강화
- 일괄 시 예상 골드와 HP/공격 변화 미리보기
- 상한이면 다음 상한 해금 조건 표시
- 골드 부족 시 부족량 표시

자동으로 보유 골드를 전부 써버리는 버튼은 확인 없이 실행하지 않는다.

---

# 6. 중복 직접 사용

모집 캐릭터 중복 1장:

- 해당 캐릭터 +1 즉시 가능.
- +50이면 직접 사용 불가, 분해 또는 향후 별도 처리.

중복 획득 결과 화면에서:

1. `+1 적용`
2. `공용 재화로 분해`

중 선택 가능 후보. 기본 행동을 자동 분해로 만들지 않는다.

다회 모집 결과에서는 일괄 정책을 선택할 수 있다.

---

# 7. 공용 +성장 재화

가칭 `혼의 파편 / soul_shard`.

중복 분해량:

| 희귀도 | 분해 획득 |
| --- | ---: |
| C | 4 |
| B | 8 |
| A | 20 |
| S | 70 |
| SS | 220 |

대상 캐릭터 +1 비용:

| 대상 | +1 비용 |
| --- | ---: |
| STORY | 80 |
| C | 16 |
| B | 32 |
| A | 80 |
| S | 280 |
| SS | 880 |

같은 희귀도 중복을 분해해 다시 같은 희귀도 다른 캐릭터에 쓰면 **직접 중복의 25% 효율**.

예:

- S 중복 1장 직접 → S 해당 캐릭터 +1.
- S 중복 4장 분해 → 280 → 다른 S +1.

SS도 동일하게 직접 중복이 4배 효율.

스토리 캐릭터는 모집 중복이 없으므로 공용 재화로 +레벨을 올린다.

---

# 8. +레벨 비용 누적

현재 후보는 +1마다 같은 soul_shard 비용을 사용한다.

장점:

- 이해가 쉬움.
- +후반 비용 폭증으로 중복을 사실상 무의미하게 만들지 않음.

따라서 +0→+50 총 비용:

- STORY: 4,000
- C: 800
- B: 1,600
- A: 4,000
- S: 14,000
- SS: 44,000

이 값은 혼의 제련소 지급량과 모집 중복량을 함께 보고 반드시 시뮬레이션한다.

+레벨 구간별 비용 증가가 필요하면 +20/+40 이후 소폭 계단형 증가를 고려하되 첫 구현은 단순 고정비를 우선한다.

---

# 9. 진화 해금 기본 레벨

기본 후보:

- F2: Base Lv10 이상
- F3: Base Lv30 이상 + 해당 캐릭터/카테고리 진화재료

스토리 진행상 F2/F3를 더 늦게 해금하고 싶다면 시스템 전체 기능 해금 시점을 별도로 둔다.

캐릭터마다 특별한 해금 스테이지가 있어도 가능하나 모든 캐릭터를 다른 SPECIAL에 묶지 않는다.

---

# 10. 진화재료 기본 단위

1차 기본 재료:

- `evo_fragment` 일반 파편
- `evo_core` 상급 핵
- `evo_crown` 희귀 심층재료

8속성마다 재료 8종을 따로 만드는 것은 기본안이 아니다.

---

# 11. 희귀도별 F2/F3 기본 요구량

아래는 캐릭터별 조정 전 기준표.

| 분류 | F2 골드 | F2 fragment | F2 core | F3 골드 | F3 fragment | F3 core | F3 crown |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| STORY/C | 2,500 | 5 | 0 | 14,000 | 24 | 2 | 0 |
| B | 3,500 | 7 | 0 | 20,000 | 34 | 3 | 0 |
| A | 5,000 | 10 | 1 | 30,000 | 50 | 5 | 0~1 |
| S | 7,500 | 16 | 1 | 46,000 | 76 | 8 | 1 |
| SS | 10,000 | 22 | 2 | 65,000 | 105 | 12 | 2 |

상대 요구량이 대략 C:SS ≈ 1:4~5가 되도록 한다.

캐릭터별 ±20% 내 조정은 허용. 그 이상 차이는 특별한 이유를 위키에 기록한다.

# 12. 특별 진화조건

사용 가능:

- 특정 상시 SPECIAL 첫 클리어
- 특정 보스 재료 1개
- 캐릭터 개인 스토리 완료

금지:

- 기간 이벤트를 놓치면 영구 진화 불가
- PvP 상위 티어만 F3 가능
- SS 중복을 F3 필수재료로 사용

---

# 13. 진화 sidegrade 보호

F3가 F2보다 모든 면에서 좋아지는 것을 강제하지 않는다.

위키 비교 UI에서:

- HP ↑/↓
- 공격/DPS ↑/↓
- 비용 ↑/↓
- 사거리 변화
- 재생산 변화
- 능력 획득/상실

을 보여준다.

이전 형태 재선택은 무료 기본 후보. 형태를 바꿀 때 별도 소모재화 없음.

---

# 14. 모집 1회 비용 후보

모집 재화 단위와 SPECIAL 지급량을 연결하기 위한 기본 후보:

- 1회: 100
- 10회: 1,000

10회는 편의 기능이며 **할인/최소희귀 보장 없음**을 기본으로 한다.

향후 10회 할인(예: 950)을 넣으면 저축 강제가 생기므로 우선 사용하지 않는다.

---

# 15. 확률 기대값 참고

후보 확률 C42/B32/A22.7/S3/SS0.3 기준:

- 평균적으로 S 이상은 약 30.3회당 1회 정도의 기대 빈도.
- SS 단독 확률은 0.3%라 단순 기대 횟수는 약 333회당 1회.

이는 천장이 아니다. 실제 사용자가 333회에 반드시 SS를 얻는다는 뜻이 아니며 UI에서도 그렇게 표현하지 않는다.

따라서 모집 재화 공급과 복각 빈도가 충분해야 한다.

---

# 16. 신규 계정 모집 지급

초기 경험 목표 후보:

- 모집 기능 정식 개방까지 무료/첫 클리어 재화로 최소 10~20회 정도를 경험 가능.
- 특정 S/SS를 지급하는 강제 튜토리얼 모집은 기본안 아님.
- 첫 10회 보장 없음.

정확한 초기 지급량은 메인 첫 클리어 보상표 작성 후 맞춘다.

---

# 17. 경제 테스트 계정

다음 프로필을 시뮬레이션한다.

## Casual

- 하루 평균 20분
- 주기 SPECIAL 충전 일부만 사용
- 메인 중심

## Regular

- 하루 45분
- 대부분 충전 사용
- 이벤트/랭크 소량

## Heavy

- 하루 90분+
- 모든 충전 사용
- 직접 반복/소탕 적극 활용

각 프로필에서 30일 후:

- 보유 캐릭터 수
- 평균 기본 Lv
- +레벨 분포
- F2/F3 수
- S/SS 기대 획득
- 남은 재화

를 측정한다.

# 18. 목표 성장 속도

정확한 일수는 테스트 후 조정하지만 방향:

- 메인을 자연스럽게 밀면서 주력 10종의 현재 장 상한을 맞출 수 있음.
- 모든 보유 캐릭터를 즉시 상한까지 키우기는 어려움.
- 새 캐릭터를 얻었을 때 후반 계정이 며칠간 초반 레벨부터 억지 파밍하지 않게 골드 수급은 충분.
- F3는 의미 있는 투자지만 몇 주씩 특정 재료 하나만 기다리는 구조 금지.
- SS +50은 매우 장기 목표이고 정상 성능의 전제 아님.

---

# 19. 조정 우선순위

경제가 너무 느리면:

1. 첫 클리어/주기 SPECIAL 보상 상향
2. 레벨 비용 조정
3. 진화재료 조정
4. 모집 확률 변경은 최후순위

경제가 너무 빠르면:

1. 반복 charged 보상 조정
2. 소탕/충전 공급 조정
3. 고단계 효율 조정
4. 기본 성장 체감을 약화시키는 방향은 후순위

---

# 20. LOCKED 조건

- 메인 80 첫 클리어 보상 총량 확정
- 주기 SPECIAL 보상 총량 확정
- 모집 1회 비용 확정
- 최소 30일 계정 경제 시뮬레이션
- Lv1~50 비용과 적 성장의 상관 검증
- +레벨이 Base Lv 성장보다 너무 빨리 앞서지 않음
- STORY/C/B/A/S/SS 모두 현실적인 F3 경로 존재
- 소탕권/보상충전이 에너지처럼 느껴지지 않음
