# 속성·전투 태그 카탈로그 v1

상태: `DESIGN_TARGET`

현재 프로토타입의 `LIGHT / ARMORED / ARCANE / BOSS` 체계는 v1.0 정본으로 사용하지 않는다. 플레이어 캐릭터와 적 모두 같은 속성 체계를 사용하고, `BOSS` 같은 정보는 전투 태그로 분리한다.

## 1. 속성

속성은 캐릭터/적의 본질적 분류이며 대항 능력의 주요 타겟이 된다. 전역 가위바위보는 없다.

### 무속성 `NEUTRAL`
- 특정 초자연/종족 속성에 속하지 않는 병사, 용병, 동물 일부, 일반 구조물.
- 기본 캠페인 초반의 기준점.
- `무속성 대항`도 별도 전문 역할로 존재 가능.

### 야수 `BEAST`
- 동물형, 야수형, 원시 생물.
- 빠른 이동/다수/물량만을 의미하지 않는다. 거대한 탱커도 가능.
- 시각 언어: 털/비늘/발톱/뿔/짐승 골격 등.

### 언데드 `UNDEAD`
- 해골, 망령, 시체, 저주받은 갑옷, 관/묘지 기반 존재.
- 부활/사망 연계 능력 후보가 많지만 모든 언데드가 부활하는 것은 아니다.

### 자연 `NATURE`
- 식물, 균류, 정령, 살아 있는 지형, 숲 생물.
- 야수와 겹칠 수 있으며 필요 시 이중 속성을 허용한다.

### 마력 `ARCANE`
- 마법 생명체, 마력으로 만들어진 존재, 마도병기, 순수 마력체.
- 단순히 마법을 사용하는 인간 모두에게 자동 부여하지 않는다. 인간 마법사는 `NEUTRAL`일 수도 있다.

### 악마 `DEMON`
- 계약/저주/지옥계 존재, 악마 종족.
- 어두운 색만으로 식별하지 않고 뿔, 왜곡된 신체, 문양, 비정상적인 이동 방식 등 실루엣을 사용한다.

### 기계 `MACHINE`
- 로봇, 드론, 자동병기, 기계 생명체.
- 사람이 기계 장비를 든 것만으로 자동 기계 속성이 되지 않는다.

### 괴이 `ANOMALY`
- 기존 생물학/마법/기계 분류로 설명하기 어려운 변칙 존재.
- 공간 왜곡, 비정상 형상, 조합체, 현실 오류 같은 후반 적/캐릭터에 사용.
- `ANOMALY`를 모든 특이한 디자인의 쓰레기통으로 남발하지 않는다.

## 2. 이중 속성

- 기본은 1속성.
- 콘셉트가 명확할 때 최대 2속성까지 허용한다.
- 예: 기계+괴이, 야수+자연, 마력+악마.
- 여러 속성을 가진 대상에게 어떤 대항 보너스가 중첩되는지는 능력별로 명시한다.
- 기본 피해 보너스는 가장 강한 하나만 적용하는 방식 또는 명시적 중첩 허용 중 하나를 시스템에서 통일해야 한다. 구현 전 simulation 규칙으로 확정한다.

## 3. 전투 태그

태그는 속성과 별개다. 별도의 두 번째 상성표를 만들지 않는다.

### 핵심 태그 후보

- `ARMORED` — 중갑/장갑
- `FLOATING` — 지면과 분리된 부유 이동
- `GIANT` — 거대 체급
- `BOSS` — 보스/준보스 판정
- `STRUCTURE` — 구조물/고정 포대/이동 성채
- `SUMMON` — 다른 유닛이 생성한 소환체
- `SWARM` — 다수 개체/군집 콘셉트
- `SHIELDED` — 별도 보호막 시스템을 실제 구현할 경우 사용

태그는 필요한 만큼 늘릴 수 있으나 능력 하나 만들 때마다 즉흥 태그를 만들지 않는다.

## 4. 전투 중 표시

- 모든 속성/태그를 머리 위에 상시 띄우지 않는다.
- 상태 변화가 중요한 `Slow/Freeze/Weaken/Shield` 등만 전투 중 명확히 표시한다.
- 적의 본질적 속성은 외형 + 사전 출현 목록 + 도감으로 학습한다.
- 미발견 적은 실루엣 + `???`이므로 첫 조우 전에는 정확한 속성을 숨길 수 있다.

## 5. 도감 정보

발견 후 도감에는 최소 다음을 공개한다.

- 속성 1~2개
- 전투 태그
- 주요 능력/상태효과
- 사거리 성향
- KB 특성
- 주요 등장 스테이지
- 대항 팁은 직접 정답을 강요하지 않는 짧은 설명으로 제공 가능

## 6. 1차 메인 도입 순서

- 1장: NEUTRAL / BEAST
- 2장: NATURE / UNDEAD
- 3장: ARCANE / DEMON
- 4장: MACHINE / ANOMALY

초반 한 장에 모든 속성을 한꺼번에 던지지 않는다.
