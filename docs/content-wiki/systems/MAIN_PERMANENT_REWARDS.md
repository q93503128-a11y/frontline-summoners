# 메인 80스테이지 영구 보상 상세 규칙

상태: `DESIGN_TARGET`  
상위: `INITIAL_MAIN_4_CHAPTERS.md`

목표: 메인 첫 클리어가 캐릭터 레벨 외에도 계정 전체의 성장 체감을 만들되, 이동속도/출격한도/사거리처럼 전투 정체성을 깨는 축은 사용하지 않는다.

---

# 1. 적용 순서

HP/공격 예시:

```text
formLv1Stat
× baseLevelMultiplier
× plusLevelMultiplier
× (1 + allPermanentBonus + eligibleGroupBonus)
```

영구 보너스끼리는 **합연산**한다. 같은 +3%를 여러 번 얻을 때 복리 곱연산하지 않는다.

예:

- 전체 HP +12%
- FRONTLINE HP +10%
- 현재 형태가 FRONTLINE 대상

→ 최종 영구 HP 배율 ×1.22.

---

# 2. 보상 적용 그룹

캐릭터 형태는 필요 시 `rewardScopes[]`를 가진다.

1차 그룹:

- `FRONTLINE`
- `RANGED`
- `AREA`

이 그룹은 획득 희귀도/속성과 별개다.

## FRONTLINE

전선을 직접 받아내거나 근거리에서 유지하는 형태.

- 자동으로 standingRange 숫자만 보고 판정하지 않는다.
- 캐릭터 형태 위키에 명시.

## RANGED

중장거리/초장거리에서 보호를 전제로 싸우는 형태.

- 사거리 숫자 하나로 자동 판정하지 않고 형태 정체성을 기준으로 명시.

## AREA

공격 targeting이 실제 AREA인 형태.

- SINGLE은 포함하지 않는다.

한 형태가 FRONTLINE+AREA처럼 여러 그룹을 가질 수 있다. 단 동일 스탯 보너스 그룹이 중복되어 의도 이상으로 강해지는지 확인한다.

# 3. 경제 영구 보너스

## 시작 보급

```text
actualStartingSupply = round(stageStartingSupply × (1 + startSupplyBonus))
```

개인 경제를 쓰는 협동에서는 각 플레이어 계정 보너스를 자신의 시작 보급에 적용.

## 처치 보급

적 사망 시 협동에서도 **활성 플레이어 각각에게 기본 처치 보급을 지급**하는 것을 기본 후보로 한다. 마지막 타격자 독점 금지.

```text
personalKillSupply = round(enemyReward × stageKillMultiplier × (1 + accountKillSupplyBonus))
```

두 플레이어의 보너스가 다르면 각자 다른 양을 받는다.

## 보급소 강화비

```text
actualWorkerCost = round(baseWorkerCost × (1 - workerCostReduction))
```

1차 완성 영구보상 총 감소 상한 후보: 25%.

## 재생산 감소

```text
adjustedRecharge = baseRecharge × (1 - accountRechargeReduction)
finalRecharge = max(60F, round(adjustedRecharge))
```

1차 메인 영구보상 총 감소 목표는 16% 수준. 시스템 상한 후보 25%, 이후 60F 하한.

# 4. 거점 HP

```text
playerBaseHp = round(stageBaseHp × (1 + baseHpBonus))
```

PvP 랭킹전에서는 메인 영구 보너스를 표준화하므로 적용하지 않는다.

협동 공유 거점 HP는 두 계정 중 높은 보너스/평균/호스트 값을 사용하지 않는다. **협동 모드 표준 거점 보너스 정책을 서버가 하나로 결정**해야 한다.

1차 후보:

```text
teamBaseBonus = average(player1BaseBonus, player2BaseBonus)
```

친구 캐리로 고성장 한 명의 영구보너스가 팀 전체를 그대로 덮지 않게 평균을 우선한다. 이 값은 협동 플레이테스트 후 LOCKED.

# 6. 4장 완료 시 누적값

전체 계정 공통:

- 전체 HP: +36%
- 전체 공격: +36%
- 거점 HP: +40%
- 시작 보급: +40%
- 처치 보급: +32%
- 보급소 강화비: -12%
- 재생산: -16%

추가 그룹 보너스는 형태에 따라 별도.

이 누적량은 강하게 체감되지만 기본 Lv50 ×10 성장보다 주성장축이 되지는 않아야 한다.

# 8. 역할 보너스 UI

캐릭터 상세에서 현재 형태가 받는 영구 그룹 보너스를 표시한다.

예:

`현재 형태 보너스: 전체 HP +36% / FRONTLINE HP +15%`

플레이어가 왜 같은 레벨인데 형태별 최종 HP 차이가 더 커졌는지 이해할 수 있어야 한다.

---

# 9. PvP

랭킹전:

- 전체 HP/공격/거점/시작보급/처치보급/worker/recharge 영구 보너스 표준화 또는 제거.
- 계정 진행으로 랭킹 스탯 우위가 생기지 않음.

친선 실제성장:

- 실제 영구 보너스 적용 가능.

일반전은 랭킹과 같은 표준화가 기본.

---

# 10. LOCKED 전 검증

- 80개 첫 클리어 후 누적 합계 자동 검사
- 이동속도/출격한도/사거리 보상 0개 확인
- 재생산 감소 후 60F 하한 확인
- worker cost reduction이 음수/0 비용을 만들지 않음
- 역할 그룹이 모든 F1/F2/F3에 정의됨
- 협동 팀 거점 보너스 정책 확정
- PvP 표준화에서 전부 제거되는지 테스트
- 저장 마이그레이션에서 중복 영구 보상 수령 방지
