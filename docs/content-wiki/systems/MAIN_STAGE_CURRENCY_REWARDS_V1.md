# 메인 80 — 일반 재화 보상 상세 목표 v1

상태: `DESIGN_TARGET`  
상위: `MAIN_PERMANENT_REWARDS.md`, `PROGRESSION_NUMERICAL_TARGETS.md`

이 문서는 메인 80개의 **영구 보상 이외** 일반 재화 지급량을 정한다. HP/공격/보급 등 영구 성장 효과는 `MAIN_PERMANENT_REWARDS.md`가 정본이며 여기서 중복 정의하지 않는다.

목표:

- 메인 첫 클리어 자체가 확실히 보람 있을 것.
- 메인 반복이 황금 수송대 같은 전용 파밍 SPECIAL보다 효율적이지 않을 것.
- 모집 재화를 충분히 주되 메인만으로 고희귀 수집이 자동 완성되지는 않을 것.
- 스테이지별 `소량/대량` 같은 모호한 표현을 실제 구현에 남기지 않을 것.

---

# 1. 공통 지급 규칙

한 stage의 정상 첫 클리어:

```text
FIRST_CLEAR = firstGold + firstRecruitCurrency + milestoneExtras + permanentReward + unlocks
```

재클리어:

```text
REPEAT_NORMAL = repeatGold
```

- 일반 메인 재클리어에서 모집 재화 반복 지급 없음.
- repeatGold는 아래 표에 명시.
- NORMAL_CLEAR은 솔로 또는 허용된 정상 협동 실제 승리.
- 협동이라고 보상 감액/증액하지 않는다.
- FIRST_CLEAR는 계정당 1회.
- 소탕은 FIRST_CLEAR를 만들 수 없다.
- 소탕으로는 repeatGold만 받는다.

이 합계는 메인 영구보상, SPECIAL 첫/반복 보상, 이벤트/PvP 보상을 제외한 값이다.

의도:

- 메인만 밀어도 상당한 모집 경험을 할 수 있음.
- 한 캐릭터 Lv1→50 기본 골드 목표 222,230과 비교하면 메인80 첫클리어 골드는 대략 한 캐릭터 완전강화 한 번 분량이지만 실제 진행 중에는 여러 캐릭터를 분산 강화하므로 황금 수송대/반복 플레이가 여전히 의미 있음.
- 반대로 골드 파밍 SPECIAL을 장시간 강제하지 않도록 실제 플레이테스트에서 공급량을 검증한다.

# 8. 일반 메인 반복 보상

현재 repeatGold는 각 stage firstGold의 약 20%를 10단위로 내림한 DESIGN_TARGET이다.

의도:

- 좋아하는 메인 스테이지를 다시 해도 완전 무보상은 아님.
- 하지만 같은 진행도의 황금 수송대 charged reward보다 시간 효율이 낮음.
- 메인 반복으로 모집 재화/희귀 진화재료를 무한 파밍할 수 없음.

밸런스 테스트에서 메인이 전용 파밍 SPECIAL보다 효율적이면 repeatGold를 먼저 낮추고 FIRST_CLEAR 보상은 가능한 유지한다.

---

# 9. 소탕

메인 소탕:

- NORMAL_CLEAR 후 sweepEligibility가 true인 스테이지.
- 소탕권 1장.
- repeatGold 획득.
- 모집 재화/영구 보상/milestone extra 재지급 없음.

메인의 거의 모든 일반 stage는 첫 정상 클리어 후 소탕 가능을 기본으로 한다. 튜토리얼/특수 스토리전 중 재클리어 자체가 불필요한 예외만 false 가능.

---

# 10. 협동

- 협동 NORMAL_CLEAR도 같은 FIRST_CLEAR 지급.
- 참가자 각자의 계정 firstClear 여부를 독립 판정.
- 한 명이 이미 클리어했고 한 명이 처음이면 처음인 플레이어만 FIRST_CLEAR를 받는다.
- 기본 반복 보상은 각자 동일 repeatGold.
- 같은 전투를 했다고 팀 보상을 합쳐 2배 분배하지 않는다.

---

# 11. 경제 QA

LOCKED 전 반드시 측정:

- 새 계정이 Ch1 완료 시 핵심 4~6종을 권장 레벨까지 올릴 수 있는지.
- Ch2~4에서 한 덱 10종을 모두 상한까지 올리는 것이 너무 쉽거나 너무 강제 파밍인지.
- 모집 84.7회분 + SPECIAL/이벤트 공급을 합쳤을 때 S/SS 획득 경험이 목표와 맞는지.
- 메인 repeatGold가 황금 수송대 효율을 침범하지 않는지.
- evo_fragment/core/crown이 진화의 문을 무의미하게 만들지 않는지.
- 반대로 3형태 한 명 만들기 위해 과도한 반복 파밍이 필요한지.
- 소탕권 44장 + SPECIAL/이벤트 공급이 편의 기능으로 충분한지.

이 문서의 숫자는 경제 시뮬레이션/사람 플레이를 통과한 뒤에만 TESTED/LOCKED로 올린다.
