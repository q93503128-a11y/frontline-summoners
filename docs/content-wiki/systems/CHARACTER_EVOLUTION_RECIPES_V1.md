# 초기 43종 캐릭터 — F2/F3 개별 진화 Recipe v1

상태: `DESIGN_TARGET`  
상위: `GROWTH_RECRUITMENT_DESIGN.md`, `PROGRESSION_NUMERICAL_TARGETS.md`

이 문서는 초기 43종의 진화 비용을 캐릭터별로 확정 가능한 목표값까지 내려놓는다. 전투 밸런스와 재화 공급 테스트 전이므로 `LOCKED`가 아니다.

재료:

- `evo_fragment` — 기본 진화 조각
- `evo_core` — 중급 핵심
- `evo_crown` — 고급 재료
- Gold

속성별 8종 재료를 만들지 않는다.

---

# 1. 공통 조건

F2:

- Base Lv10 이상
- F1 보유
- 아래 F2 recipe 소모

F3:

- Base Lv30 이상
- F2 해금 완료
- 아래 F3 recipe 소모

+레벨은 진화 요구조건에 사용하지 않는다.

형태를 한 번 해금하면 이후 F1/F2/F3 전환은 무료가 기본이다.

`fragment / core / crown / gold`

`18 / 2 / 0 / 6,000`

= evo_fragment 18 + evo_core 2 + crown 0 + Gold 6,000.

# 11. 진화 UI 표시

캐릭터 상세에서 다음을 동시에 보여준다.

- 현재 형태
- 다음 형태 이름/실루엣 preview
- Base Lv 조건
- 보유/필요 fragment
- 보유/필요 core
- 보유/필요 crown
- Gold
- 진화 전/후 주요 차이

재료가 부족하면 어떤 SPECIAL에서 얻는지 바로가기 제공 가능.

미해금 F3의 전체 전투 수치를 숨길지는 UX 후보이나, 적어도 진화 방향/필요 재료는 외부 위키 없이 확인 가능해야 한다.

# 12. 진화 실행

진화는 transaction으로 처리한다.

검증:

1. 캐릭터 소유
2. Base Lv
3. 이전 형태 해금
4. Gold
5. 각 재료
6. 재료/Gold 차감
7. form unlock
8. save commit

중간 실패로 재료만 빠지는 상태 금지.

# 13. 이전 형태 선택

F3를 열어도 F1/F2가 삭제되지 않는다.

- 해금된 형태 목록 유지
- 전투 편성에는 현재 선택 형태 저장
- 형태 전환 비용 없음
- 형태 전환으로 Base Lv/+Lv 초기화 없음

PvP loadout snapshot은 선택 형태를 포함한다.

# 14. 재료 공급 검산

현재 메인80 milestone DESIGN_TARGET 공급:

- fragment 104
- core 22
- crown 4

이는 **전체 43종 진화를 메인 첫클리어만으로 끝내기 위한 양이 아니다.**

진화의 문과 이벤트/상시 SPECIAL이 주 공급처 역할을 한다.

그러나 정상 덱의 핵심 캐릭터 몇 명을 F2/F3로 만들기 위해 지나친 반복이 필요해서는 안 된다.

목표:

- Ch1 후반: 핵심 F2 2~4명 자연스럽게 가능
- Ch2 완료 전후: F2 다수 + 일부 고급 F2
- Ch3 진행: 핵심 F3 2~4명 접근
- Ch4 진행: 주력 덱 F3 확대

정확한 평균 파밍 횟수는 진화의 문 보상과 함께 시뮬레이션한다.

# 15. 경제 위험

다음이면 recipe 재조정:

- C/스토리 F3 한 명이 너무 싸서 아무 선택 없이 전원 즉시 F3
- 반대로 Ch3에서 주력 한 명 F3에 수십 회 반복 파밍 필요
- S/SS는 뽑아도 재료 때문에 장기간 F1 고정
- crown이 과도한 병목
- Gold보다 재료만 항상 병목 또는 반대
- 진화의 문 최고단계만 압도적으로 효율적이라 낮은 단계가 무의미

---

# 16. LOCKED 전 테스트

43종 각각:

- F2/F3 비용 대비 실제 형태 변화 가치
- 동일 rarity 내 지나친 비용 편차 여부
- 낮은 rarity 진화의 후반 가치
- S/SS 진화가 강제 중복 없이 가능한지
- main + periodic SPECIAL 공급 곡선
- 소탕 사용 시 진화 속도
- 협동으로 높은 진화의 문을 도움받았을 때 성장곡선 붕괴 여부

필요하면 개별 캐릭터 recipe를 ±10~15% 범위에서 조정하고 변경 이유를 기록한다.
