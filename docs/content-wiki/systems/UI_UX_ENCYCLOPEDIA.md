# UI/UX·편성·도감 상세 기획

상태: `DESIGN_TARGET`

목표는 PC와 모바일 가로화면에서 같은 기능을 억지 축소하지 않고, 작은 전투 화면에서도 정보가 읽히며 개발툴처럼 네모난 패널만 반복되지 않는 UI를 만드는 것이다.

---

# 1. 공통 시각 언어

게임 UI는 전선의 지휘소를 모티프로 한다.

사용 가능한 형태 언어:

- 천막/깃발
- 리본/문장
- 얇은 금속 테두리
- 목재 프레임
- 양피지/지도
- 봉인/인장

금지:

- 모든 화면을 동일한 회색 직사각형 카드로 구성
- 장식 때문에 텍스트 대비 저하
- 모바일에서 미세한 버튼을 PC 그대로 축소
- 중요한 숫자를 hover에만 숨김

---

# 2. 반응형 기준

최소 검증 화면:

- 360×640 계열 가로 대응 여부
- 390×844
- 412×915
- 768×1024
- 1280×720
- 1920×1080

실제 전투는 가로 orientation을 기본으로 하되 브라우저 UI/노치/safe area를 고려한다.

텍스트는 80/100/125/150% 확대에서도 핵심 버튼이 겹치지 않는지 검사한다.

---

# 3. 메인 메뉴

1차 핵심 진입:

- 출정
- 편성
- 성장
- 모집
- 도감
- 친구
- PvP
- 설정/계정

SPECIAL은 출정 내부에서 메인과 명확히 구분한다.

신규 알림은 필요한 메뉴에 작은 배지로 표시하고 모든 메뉴에 붉은 점을 남발하지 않는다.

---

# 4. 출정 화면

상단 또는 큰 탭:

- 메인
- SPECIAL
- 이벤트
- 기록전

SPECIAL 내부:

- 상시
- 주기
- 이벤트

필터가 너무 깊어지면 좌우 탭 + collection 카드 조합을 사용한다.

---

# 5. 스테이지 카드

표시:

- 이름
- 난이도 1~12
- 클리어 상태
- 솔로/협동 아이콘
- 첫 클리어 보상 핵심
- 영구 보상 여부
- 발견한 적 실루엣/아이콘

SPECIAL이면 추가:

- 남은 시간/복각 정보
- 보상 충전
- 내부 단계 진행

`난이도 7` 숫자만 던지지 않고 시각 단계 표시를 함께 사용한다.

---

# 6. 스테이지 상세

입장 전 확인:

- 맵 이름/지역
- 난이도
- 출현 적
- 미발견 적은 실루엣 + ???
- 발견 적 탭 → 적 도감
- 첫 클리어 보상
- 반복 보상
- 영구 보상
- 솔로 시작
- 친구 초대
- 공개 협동
- 소탕

소탕은 조건을 만족할 때만 활성화하며 비활성 이유를 설명한다.

---

# 7. 편성

## 레이아웃

- 하단/상단 10칸 덱
- 보유 캐릭터 grid
- 빠른 필터 chips
- 상세 필터 버튼
- 검색

## 드래그

PC:

- 카드 drag → 원하는 슬롯
- 슬롯끼리 drag swap

모바일:

- 짧은 탭 = 선택/정보
- long press = drag 시작
- drag 중 대상 슬롯 확대/하이라이트

드래그가 실패했는지 성공했는지 애니메이션으로 명확히 보여준다.

---

# 8. 편성 필터

빠른:

- 전체
- 스토리
- C
- B
- A
- S
- SS

상세:

- 속성 대항
- 역할
- 단일/범위
- 비용대
- 사거리대
- 기본 레벨
- +레벨
- 형태
- 최근 획득
- 즐겨찾기

여러 필터를 조합 가능하게 하되 현재 필터가 무엇인지 상단에 요약한다.

---

# 9. 미획득 처리

도감:

- 실루엣
- ???
- 발견/획득 조건에 따라 일부 힌트 후보

편성:

- 미획득 캐릭터 자체를 표시하지 않음

모집 배너의 라인업 확인:

- 획득 가능 캐릭터는 이름/희귀도/확률 확인 가능
- 도감에서 미획득 상태더라도 모집 라인업 정보와 충돌하지 않게 별도 표시 정책을 둔다.

---

# 10. 아군 도감

획득 후 보여줄 핵심:

- 현재 형태 일러스트/미니어처
- 이름
- 획득 분류/희귀도
- 기본 Lv / +Lv
- 속성
- 전투 태그
- 역할
- HP
- 공격력
- 명목 DPS
- 사거리
- 이동속도
- KB
- 비용
- 재생산
- 공격주기
- 능력 상세
- 형태 선택
- 획득처

숫자를 숨겨 외부 위키를 필수화하지 않는다.

---

# 11. 적 도감

발견 후:

- 이름/실루엣
- 속성/태그
- 기준 HP/공격
- 사거리
- 공격주기
- 이속/KB
- 능력
- 특징 요약
- 주요 등장처

스테이지의 실제 magnification 때문에 HP가 달라지는 경우 `기준 능력치`와 해당 스테이지 배율을 혼동하지 않게 한다.

---

# 12. 성장 화면

캐릭터 선택 후:

- 현재 형태
- 기본 Lv
- +Lv
- 다음 기본 레벨의 HP/공격 변화
- 비용
- 골드 잔액
- +레벨 재화/중복 상태
- 진화 조건

한 번에 너무 많은 숫자를 펼치지 않고 기본/상세 탭을 둘 수 있다.

---

# 13. 진화 화면

F1/F2/F3 비교:

- 실루엣/외형 미리보기
- 주요 스탯 변화
- 비용/재생산/사거리 변화
- 새/사라지는 능력
- 요구 재료

`강화됩니다` 같은 모호한 문장만 표시하지 않는다.

sidegrade 형태이면 무엇이 좋아지고 나빠지는지 양쪽을 보여준다.

---

# 14. 모집 화면

- 현재 시리즈 이름
- 남은 기간/복각 정보
- S 목록
- SS 정확히 1명
- 확률 상세
- 공통 C/B/A 설명
- 1회/다회 모집
- 보유 모집 재화

천장/누적 선택권 UI는 존재하지 않는다.

연출 스킵:

- 이미 본 일반 연출 즉시 스킵
- 신규 S/SS는 첫 획득 시 강조
- 사용자가 전체 연출 스킵 설정 가능 후보

---

# 15. 전투 HUD

필수:

- 아군/적 거점 HP bar + 숫자
- 현재/최대 보급
- 보급 증가량 또는 보급소 레벨
- 10개 또는 협동 개인 5개 생산 버튼
- 각 비용
- 재생산 게이지
- 거점 병기
- 일시정지(솔로)
- 1×/2×(해금된 재클리어)
- 전투 시간

캐릭터 버튼의 쿨다운은 남은 비율이 한눈에 보여야 한다.

---

# 16. 전투 상태 피드백

생산 불가 이유:

- 보급 부족
- 재생산 중
- 출전 관련 시스템 제한이 있다면 해당 이유

버튼을 눌렀는데 아무 반응이 없는 상태 금지.

보급 소비 시 숫자/게이지가 즉시 반응한다.

---

# 17. 전투 중 상태 아이콘

상시 속성 아이콘은 표시하지 않는다.

일시 상태:

- Slow
- Freeze
- Weaken
- Strengthen 활성

등 실제 의사결정에 필요한 상태만 간결하게 표시한다.

동시에 아이콘이 과도하게 겹치면 우선순위/통합 표현을 사용한다.

---

# 18. 협동 HUD

- 내 5칸 생산
- 내 보급/보급소
- 팀 기지 HP
- 공유 병기
- 파트너 이름/연결 상태
- 파트너 보급소 레벨 정도는 보조 표시 후보
- 빠른 통신

파트너의 5개 생산 버튼까지 내가 조작할 수 있는 것처럼 보이지 않게 한다.

---

# 19. 재접속 UI

끊김 감지 시:

- 즉시 패배 화면 금지
- 재연결 상태 표시
- 남은 유예를 과도하게 위협적으로 표시하지 않음

복귀하면 현재 전투 상태로 자연스럽게 전환한다.

---

# 20. PvP UI

일반전:

- 일반전임을 명확히
- 티어 변화 없음

랭킹전:

- 현재 티어
- 현재 rating 변화
- 시즌
- 순위
- 승/패 후 변화 이유

친선전:

- 표준/실제 성장
- 규칙
- 방 인원

모드를 잘못 들어가 rating을 잃는 일이 없게 시각적으로 구분한다.

---

# 21. 결과 화면

표시 순서:

1. 승리/패배
2. 첫 클리어/신기록 여부
3. 보상
4. 영구 보상/상한 해제
5. 새 캐릭터/진화 해금
6. 재도전/다음 스테이지

일반 반복전에서는 긴 연출을 줄인다.

---

# 22. 소탕 UI

소탕 가능 시:

- 필요한 소탕권
- 현재 보유량
- 받을 보상
- 충전 소모 여부
- 여러 회 연속 소탕을 지원할 경우 최대 횟수

실수 방지를 위해 희귀한 충전/소탕권을 대량 사용할 때 요약 확인을 제공한다.

---

# 23. 접근성과 가독성

- 색만으로 상태 구분하지 않음
- 아이콘 + 텍스트/형태 병행
- 작은 글자 과용 금지
- 중요 정보 대비 확보
- 진동/화면 흔들림/플래시 강도 설정 후보
- 사운드 개별 볼륨

---

# 24. UI QA 체크

- 텍스트 잘림
- 버튼 겹침
- 모바일 손가락 가림
- safe area
- 10칸 덱 가독성
- 5칸 협동 덱 가독성
- 미획득 캐릭터가 편성에 노출되지 않는지
- 도감 ??? 처리
- S/SS 연출 스킵
- 랭킹/일반전 혼동
- 2배속 상태
- 소탕 보상 미리보기
- 결과 화면 중복 지급처럼 보이는 연출

화면 구현 후 해상도별 스크린샷을 위키/감사 기록과 연결한다.
