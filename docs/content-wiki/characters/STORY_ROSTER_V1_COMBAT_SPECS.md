# 모집 캐릭터와의 비교 기준

- 징집병/방벽기사는 저비용 C 벽/러셔보다 무료라서가 아니라 서로 다른 비용/HP/재생산 trade-off로 공존.
- 수렵창병은 에르시아보다 싸고 BEAST 대항, 에르시아는 더 긴 일반 사거리/효율.
- 화염술사는 리에나와 같은 한방 광역이지만 NATURE 대항/사거리 구조로 분리.
- 이단주술사는 미레이유/레일러보다 짧고 싸며 형태 유연성으로 차별.
- 공허현자는 SS가 아니라 스토리 고비용 결정타이며 SS와 상징성/효율이 직접 연결되지 않음.

# LOCKED 전 검사

- Lv1~50 성장 후 저비용 캐릭터가 무의미해지지 않는가
- 1장 획득 시점 비용을 실제 보급 상한으로 생산 가능한가
- 신규 획득 직후 해당 역할을 배울 스테이지가 존재하는가
- F1/F2/F3에 선택 이유가 있는가
- 모집 C/B/A/S/SS가 완전 상위호환하지 않는가
- 협동 5칸에서도 기본 역할이 지나치게 분산되지 않는가
