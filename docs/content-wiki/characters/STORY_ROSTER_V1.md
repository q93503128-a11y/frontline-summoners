# 스토리/기본 캐릭터 10종 v1 재설계

상태: `REWORK` → 상세 수치 작성 후 `DESIGN_TARGET`

현재 `content/units/chapter-01.json`의 10종은 전투 프로토타입으로 사용된 흔적을 재료로 삼되, **C/B/A/S/SS 희귀도는 전부 제거**하고 외형·속성·3형태·역할 중복을 다시 설계한다. 내부 ID를 유지할지는 저장 마이그레이션 비용을 보고 결정한다.

스토리 캐릭터는 낮은 등급이 아니다. 모집을 하지 않아도 기본 전투 문법을 완주할 수 있게 만드는 확정 획득 로스터다.

---

## 01. 징집병

- 기존 ID 후보: `militia`
- 획득: 시작부터
- 속성: NEUTRAL
- 역할: 초저비용 물량 / 기본 전선 유지
- 핵심: 가장 싸고 빠르게 다시 나오는 기본병. 공격 성능은 낮지만 후반에도 값싼 전선 유지용으로 쓸 이유가 있어야 한다.
- 외형: 평범한 인간 병사이되 너무 현대적 군복처럼 보이지 않게, 큰 둥근 방패 없이 짧은 창/몽둥이와 여행 배낭으로 가벼운 실루엣.
- 1형태: 급히 모인 징집병.
- 2형태: 정규 보병대. 갑옷과 창이 정돈되지만 비용/재생산도 약간 달라질 수 있다.
- 3형태: 노련한 전선병. 단순 체력 상향만이 아니라 공격주기/KB/비용 중 일부를 바꿔 1형태 물량형과 선택지가 갈릴 수 있다.
- 특수능력: 없어도 됨.

## 02. 방벽기사

- 기존 ID 후보: `guard`
- 획득: 1장 초반
- 속성: NEUTRAL
- 태그: ARMORED
- 역할: 저공격 고HP 벽
- 핵심: 공격보다 버티는 시간이 가치인 기본 탱커.
- 외형: 키보다 넓은 직사각 방패 + 짧은 다리로 작은 화면에서도 `벽`으로 읽히게.
- 1형태: 방벽기사.
- 2형태: 성문수비대. 더 두꺼운 방패, 느려질 수 있음.
- 3형태: 이동 성벽. 공격은 더 포기하고 비용/HP/KB 구조를 바꾸는 순수 벽 형태 후보.
- 능력: 단순 깡HP형 유지 가능.

## 03. 수렵창병

- 기존 ID 후보: `hunter`
- 획득: 1장 초반
- 속성: NEUTRAL
- 역할: 긴 근접 사거리 / 야수 대항
- 핵심: 전열 뒤에서 찌르며 BEAST 대상 전문 효율을 가진 첫 대항 캐릭터.
- 외형: 가벼운 사냥복 + 길고 얇은 사냥창 + 어깨의 가죽끈/덫.
- 1형태: 수렵창병.
- 2형태: 큰짐승 사냥꾼. 더 긴 창과 높은 단발 피해, 공격주기 증가 후보.
- 3형태: 왕실 수렵대. BEAST 대항 강화 또는 범위가 얇게 늘어나는 방향 후보.
- 약점: 근접 돌파를 허용하면 불리함.

## 04. 결투검사

- 기존 ID 후보: `duelist`
- 획득: 1장 중반
- 속성: NEUTRAL
- 역할: 짧은 선딜 / 단일 근접 DPS
- 핵심: 능력보다 빠른 공격 타이밍과 높은 단일 효율이 정체성.
- 외형: 한손 세검 또는 얇은 장검, 큰 갑옷 대신 긴 코트/허리 망토. 방벽기사와 실루엣 반대.
- 1형태: 결투검사.
- 2형태: 검무가. 공격 빈도/KB가 바뀌는 연속전 스타일.
- 3형태: 일섬검객. 공격 빈도를 낮추는 대신 매우 빠른 선딜의 큰 단발형으로 역할 전환 후보.
- 특수능력: 없어도 됨.

## 05. 청창대

- 기존 ID 후보: `lancer`
- 획득: 1장 중반
- 속성: NEUTRAL
- 태그: ARMORED 후보
- 역할: 중거리 유지형 / 전열 교대
- 핵심: 수렵창병보다 비싸고 가까우며 더 튼튼한 중거리 창대.
- 외형: 여러 겹 천 갑옷 + 넓은 창날 + 청색 깃발. 단순 파란 수렵창병이 되지 않도록 체형/무기 비율을 다르게 한다.
- 1형태: 청창대.
- 2형태: 장창방진. 더 긴 standing range, 느린 이동.
- 3형태: 파진창대. 공격 범위/KB/비용을 바꿔 공격적인 형태 후보.

## 06. 전투마도사

- 기존 ID 후보: `battlemage`
- 획득: 1장 중후반
- 속성: NEUTRAL 또는 ARCANE은 최종 세계관 설정 후 확정. 인간이 마법을 쓴다는 이유만으로 자동 ARCANE이 되지는 않는다.
- 역할: 첫 안정적 중거리 범위 공격
- 핵심: 다수의 약한 적을 정리하는 교과서형 광역 후열.
- 외형: 로브만 입은 마법사 대신 한 손 지팡이 + 전술 가방/보호구로 `전투 마도사` 느낌.
- 1형태: 전투마도사.
- 2형태: 전선술사. 범위/주기가 안정적.
- 3형태: 포격마도사. 사각지대와 긴 선딜을 얻는 대신 범위/한방이 커지는 변형 후보.

## 07. 화염술사

- 기존 ID 후보: `pyromancer`
- 획득: 1장 후반
- 속성: ARCANE 후보
- 역할: 고비용 광역 한방 / NATURE 대항 후보
- 핵심: 전투마도사와 겹치지 않게 느리고 강한 폭발형.
- 외형: 큰 화로/불씨 항아리를 등에 메고 양손으로 불꽃을 압축. 단순 빨간 로브 금지.
- 1형태: 화염술사.
- 2형태: 화로지기. 사거리 감소 대신 체력/한방 상승 후보.
- 3형태: 재앙의 화염술사. 큰 사각지대 + 거대한 폭발 범위를 가진 후열 포격 형태 후보.

## 08. 왕실기사

- 기존 ID 후보: `royal`
- 획득: 1장 후반
- 속성: NEUTRAL
- 태그: ARMORED
- 역할: 고비용 전열 / 범위 검격
- 핵심: 방벽기사보다 훨씬 비싸지만 버티면서 실제 전열 정리를 할 수 있는 상위 역할. 단순 상위호환이 되지 않도록 재생산과 비용이 매우 다르다.
- 외형: 높은 키, 큰 장식 깃털, 넓은 대검. 방벽기사처럼 방패형이 아님.
- 1형태: 왕실기사.
- 2형태: 근위대장. 방어/KB 강화 후보.
- 3형태: 왕의 검. 더 공격적인 비용/사거리/범위 형태로 전환 가능.

## 09. 이단주술사

- 기존 ID 후보: `heretic`
- 획득: 1장 최후반 또는 2장 초입
- 속성: ARCANE
- 역할: 장거리 광역 / 큰 사각지대 / 기술형
- 핵심: 적이 붙으면 무력하지만 안전거리에서 강한 첫 본격 blind-spot 캐릭터.
- 외형: 얼굴을 완전히 가리지 않는 비대칭 가면, 여러 부적/줄, 땅에 닿지 않는 긴 주술 도구.
- 1형태: 이단주술사.
- 2형태: 금단의 의식자. 더 긴 사거리와 더 큰 사각 후보.
- 3형태: 역주술사. 사거리를 줄이는 대신 공격주기/범위가 좋아지는 완전히 다른 운용 후보.
- 기존 S 표기는 폐기.

## 10. 공허현자

- 기존 ID 후보: `voidsage`
- 획득: 1장 최종 또는 후속 해금 재검토
- 속성: ANOMALY 또는 ARCANE+ANOMALY 후보
- 역할: 초고비용 결정타 / 보스 압박
- 핵심: `스토리 캐릭터인데 SS였던 흔적`을 제거하고, 희귀도 없이도 상징적인 고비용 유닛이 될 수 있음을 보여준다.
- 외형: 노인 마법사 클리셰보다 몸 주변 공간이 찢어진 듯한 공허 조각, 지팡이 대신 부유하는 검은 판/구체.
- 1형태: 공허현자.
- 2형태: 틈새의 현자. 공격 범위/사각 변화.
- 3형태: 공허를 본 자. 엄청난 한방 또는 다단 공간 붕괴형으로 재설계 후보.
- 보스 특효는 태그 기반 전문 효과로 남길 수 있으나 만능 보스킬러가 되지 않게 비용/선딜/생존 약점을 둔다.

# 전체 역할 점검

- 초저비용 물량: 징집병
- 순수 벽: 방벽기사
- 긴 근접/야수 대항: 수렵창병
- 빠른 단일 DPS: 결투검사
- 중거리 유지: 청창대
- 안정 광역: 전투마도사
- 느린 대형 광역: 화염술사
- 고비용 전열: 왕실기사
- 장거리 사각 기술형: 이단주술사
- 초고비용 결정타: 공허현자

현재 10종의 역할 골격은 교육용 로스터로 쓸 가치가 있어 **콘셉트는 상당 부분 회수**하되, 모집 희귀도/옛 속성/최종 외형/수치는 전면 재작업한다.
