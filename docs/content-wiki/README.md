# Frontline Summoners 콘텐츠 위키

이 디렉터리는 캐릭터, 적, 보스, 스테이지, 모집 시리즈, 이벤트를 실제 구현 전에 세밀하게 설계하는 제작 정본이다.

## 문서 역할

- `docs/CANONICAL.md`: 게임 전체 규칙과 1차 완성 범위
- `docs/GROWTH_RECRUITMENT_DESIGN.md`: 성장/모집/진화
- `docs/STAGE_SYSTEM_DESIGN.md`: 메인/SPECIAL/협동/PvP
- `docs/content-wiki/`: 콘텐츠별 상세 설계
- `content/`: 실제 런타임 데이터

기획 문서와 런타임 데이터가 다르면 한쪽을 조용히 정답으로 취급하지 않고 불일치로 판단해 문서, 데이터, 테스트를 함께 맞춘다.

## 상태

- `DESIGN_TARGET`: 구현/검증 전 목표안
- `TESTED`: 실제 동작/플레이 테스트 완료, 조정 가능
- `LOCKED`: 현재 릴리스 기준 확정
- `REWORK`: 전면 재설계 대상

## 디렉터리

- `characters/`: 플레이어 캐릭터
- `enemies/`: 일반 적
- `bosses/`: 보스
- `stages/main/`: 메인 스테이지
- `stages/special/`: SPECIAL
- `recruitment/`: 모집 시리즈/공통 풀
- `systems/`: 공통 제작 규칙
- `events/`: 기간 이벤트

## 캐릭터 페이지 필수 정보

이름/ID, 상태, 획득처, 희귀도, 시리즈, 속성, 전투 태그, 역할, 실루엣, 체형, 장비, 1/2/3형태 외형, 이동/공격/KB/사망 모션, VFX/SFX, HP, 공격, 공격주기, DPS, standing range, attack min/max, 선딜/hit frame/후딜, 이동속도, KB, 비용, 재생산, 단일/범위, 멀티히트, 효과, 대항 속성, Lv/+Lv 적용, 형태별 변화, 강점/약점, 유사 캐릭터와 차이, 플레이테스트, 연결 content 경로를 기록한다.

## 적/보스 페이지 필수 정보

이름/ID, 상태, 실루엣, 속성, 태그, 기본 스탯, 공격 구조, 사거리, 이동/KB, 전투 역할, 등장 장, 강화 배율 허용 범위, 요구하는 대응, 첫 등장 스테이지, 도감 정보, 테스트 기록을 남긴다.

## 스테이지 페이지 필수 정보

ID/이름/장 또는 SPECIAL 묶음, 상태, 난이도와 근거, 목적, 해금 조건, 솔로/협동 정책, 권장 성장, 맵 길이, 거점 HP, 시작 보급, 스폰 타임라인, 보스 페이즈, 특수 규칙, 첫/반복 보상, 영구 보상, 협동 보정, 예상 시간, 소탕/2배속, 시뮬레이션과 사람 테스트 결과를 기록한다.

## 모집 시리즈 페이지 필수 정보

시리즈 시각 언어, 실루엣 규칙, S 5~7명 목표, SS 정확히 1명, 역할 분포, 3형태 방향, 모집 화면/연출, 공통 C/B/A와의 조화, 최종 검수 상태를 기록한다.

## 작업 순서

정본 확인 → 위키 상세 설계 → 중복 검사 → content 데이터 → simulation/UI 연결 → 자동검증 → 플레이테스트 → TESTED/LOCKED → 폐기된 옛 경로 정리 순으로 진행한다.

개발 상태/내부 ID/코드 경로/테스트 메모는 위키 안에서는 사용할 수 있지만 게임 화면에는 노출하지 않는다.
