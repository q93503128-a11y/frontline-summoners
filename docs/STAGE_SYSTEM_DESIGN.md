# 전선소환전 — 스테이지·SPECIAL·협동 정밀 기획 v1.0

상위 정본: `docs/CANONICAL.md`  
세부 스테이지 위키: `docs/content-wiki/stages/`  
실제 구현 상태: `docs/IMPLEMENTATION_STATUS.md`

이 문서는 1차 완성의 메인 80스테이지, SPECIAL, 난이도, 소탕, 협동/PvP 연결 규칙을 정의한다.

---

## 1. 스테이지 계층

### 1.1 메인

- 1차 완성: 4장 × 20 = 80스테이지.
- 앞 스테이지 순차 개방이 기본.
- 장 최종 클리어는 레벨 상한 해제 + 추가 보상을 제공한다.
- 각 장은 단순 스탯 상승이 아니라 새 적/속성/공격 구조/보스 조합을 단계적으로 학습시킨다.
- 메인도 스테이지별로 솔로 전용 또는 솔로+협동을 지정할 수 있으며, 대부분은 솔로+협동 가능을 목표로 한다.
- 협동으로 처음 깨도 정상 진행/첫 클리어 보상/영구 보상/다음 스테이지 해금을 인정한다.

### 1.2 SPECIAL

SPECIAL은 큰 카드/묶음 안에 여러 내부 스테이지를 가질 수 있다.

주요 분류:

- 상시 SPECIAL
- 주기 SPECIAL
- 이벤트 SPECIAL
- 기록 SPECIAL

1회성은 별도 대분류로 만들기보다 `첫 클리어 보상 1회` 속성으로 처리한다. 스테이지 자체는 가능하면 다시 플레이할 수 있게 남긴다.

---

## 2. 난이도 1~12

난이도는 앞으로의 확장 공간을 포함한 공통 표시다.

### 2.1 1차 완성 사용 범위

- 1: 튜토리얼급
- 2: 매우 쉬움
- 3: 쉬움
- 4: 보통 이하
- 5: 보통
- 6: 제법 어려움
- 7: 현재 본편/상위 SPECIAL의 일반적인 상한
- 8: 일부 후반 보스/SPECIAL
- 9~12: 후반 성장/업데이트에서 필요할 때 사용

**1차 완성에서 9~12를 채우기 위해 억지 고난도를 만들지 않는다.**

### 2.2 난이도 산정

난이도 표시는 다음을 함께 본다.

- 정상 해금 시점의 권장 레벨/형태/+레벨 수준
- 적 총 전투력과 동시 압박
- 첫 30~60초 압박
- 보스 체급/패턴
- 필요한 속성 대응 폭
- 덱 선택 민감도
- 경제 압박과 보급소 투자 난도
- 맵 길이/사거리 관계
- 실전 클리어 시간
- 자동/샘플 시뮬레이션
- 사람 플레이테스트 성공률과 재도전 횟수

난이도 숫자를 맞추기 위해 HP/공격만 뻥튀기하지 않는다.

---

## 3. 메인 20스테이지 장 구조

모든 장을 완전히 같은 공식으로 만들 필요는 없지만 아래 흐름을 기본 골격으로 사용한다.

- ST01~04: 신규 장의 핵심 문법 소개
- ST05: 첫 복합 응용
- ST06~09: 적 조합/경제/사거리 심화
- ST10: 중간보스 또는 큰 변곡점
- ST11~14: 신규 적/속성/공격 구조 추가
- ST15~18: 복합 조합과 고난도 준비
- ST19: 최종보스 전조/준보스
- ST20: 장 최종전

세부 스폰/보상/난이도는 콘텐츠 위키에서 스테이지 단위로 확정한다.

---

## 4. 영구 보상/보물 계열

- 각 메인 스테이지 첫 클리어에 확정 영구 보상을 둘 수 있다.
- 20개 효과가 모두 달라야 할 필요는 없다.
- 같은 성장축이 여러 번 나와 누적 체감을 만드는 것을 허용한다.
- 이동속도 영구 증가와 아군 최대 출격 수 영구 증가는 사용하지 않는다.

권장 축:

- 전체/조건부 HP
- 전체/조건부 공격
- 거점 HP
- 시작 보급
- 처치 보급
- 보급소 강화 비용 감소
- 재생산 감소(최종 2초 하한 적용)

사거리 영구 증가는 전선 구조를 크게 바꾸므로 매우 제한적으로만 사용하거나 형태/캐릭터 정체성 쪽으로 돌린다.

장 마지막 스테이지:

- 1장 → Lv20 상한 + 추가 보상
- 2장 → Lv30 상한 + 추가 보상
- 3장 → Lv40 상한 + 추가 보상
- 4장 → Lv50 상한 + 추가 보상
- 이후 장은 추가 보상만

---

## 5. 재클리어 편의

### 5.1 2배속

- 첫 클리어는 1배속 기본.
- 1회 이상 클리어한 스테이지는 1×/2× 무료 전환 가능.
- 배속은 소모품이 아니다.
- 배속 때문에 simulation 규칙이 달라지지 않는다.

### 5.2 소탕

- 1회 이상 직접 클리어한 스테이지에만 사용 가능.
- 소탕권 1장으로 해당 반복 보상을 즉시 획득.
- 최초 클리어/신기록/랭킹 기록은 소탕으로 만들 수 없다.
- 소탕권이 없어도 직접 반복 플레이는 항상 가능.
- 보상 충전형 SPECIAL은 소탕권 + 충전 1회 사용.

---

## 6. SPECIAL 묶음 구조

하나의 SPECIAL 카드가 내부에 3~10개 이상의 스테이지를 가질 수 있다.

예시:

`황금 수송대`
- I 외곽의 짐마차
- II 황금 호송대
- III 무장 수송열차
- IV 왕실 금고 행렬
- V 황금왕의 대수송

단계가 올라갈수록 단순 스탯 배율뿐 아니라 적 구성, 전후열 조합, 신규 전용 적, 보스, 경제 압박이 발전한다.

이 구조는 재화전뿐 아니라 다음에도 사용한다.

- 보스 시리즈
- 속성 도전
- 진화 관련 연속전
- 이벤트 소형 캠페인
- 외전/사이드 스토리

---

## 7. 주기 SPECIAL

1차 기본 후보:

- 황금 수송대 — 골드
- 혼의 제련소 — 공용 +레벨 재화
- 진화의 문 — 진화재료
- 별빛 균열 — 모집 재화

각 콘텐츠는 3~5단계 정도로 구성할 수 있다. 모든 묶음이 똑같이 5단계일 필요는 없다.

### 7.1 보상 충전

- 플레이 입장은 무제한.
- `고효율 보상 충전`을 묶음 단위로 보유할 수 있다.
- 충전이 남아 있으면 선택한 난이도의 정상 반복 보상 지급.
- 충전을 다 써도 플레이 가능하되 반복 보상은 크게 감소.
- 각 단계 첫 클리어 보상은 충전과 별개.
- 초보는 낮은 단계, 고수는 높은 단계에 충전을 쓰는 선택이 가능해야 한다.

---

## 8. 이벤트 SPECIAL

- 기간 한정 테마/외전/이벤트 묶음.
- 4~10스테이지 정도의 소형 캠페인을 허용한다.
- 전용 적/배경/보스/룰을 적극 활용한다.
- 기간이 지나도 재등장/복각 가능한 구조를 기본으로 하여 영구 FOMO를 피한다.
- 이벤트 전용 성능 캐릭터가 있다면 복각/재획득 경로를 보장한다.

---

## 9. 기록 SPECIAL

1차 완성에서는 **두 개만 핵심으로 둔다.**

### 9.1 끝없는 전선

- 솔로 전용.
- 최고 생존 기록 갱신형.
- 개인 최고 기록의 새로운 1분 구간을 처음 돌파할 때만 1회성 보상을 지급한다.
- 예: 기존 6:42 → 새 기록 9:17이면 7/8/9분 보상을 받는다.
- 이미 받은 구간은 반복 지급하지 않는다.
- 난이도는 뒤로 갈수록 가속 상승하여 장시간 무의미한 버티기가 되지 않게 한다.

### 9.2 보스 러시

- 솔로 전용.
- 보스 연속 격파/최고 단계 기록형.
- 반복 파밍보다 기록 갱신과 첫 구간 보상 중심.
- 구체 구조는 콘텐츠 위키에서 설계한다.

기록 SPECIAL에는 소탕을 허용하지 않는다.

---

## 10. 솔로/협동 지원 플래그

모든 스테이지는 다음 중 하나를 데이터로 가진다.

- `SOLO_ONLY`
- `SOLO_OR_COOP`
- `COOP_ONLY`

기본 원칙:

- 메인: 대부분 `SOLO_OR_COOP`
- 상시/주기/이벤트 SPECIAL: 대부분 `SOLO_OR_COOP`
- 끝없는 전선/보스 러시 기록전: `SOLO_ONLY`
- `COOP_ONLY`는 이벤트/실험성 콘텐츠에서만 제한적으로 사용

## 11. 2인 PvE 협동

### 11.1 편성/경제

- 플레이어 A 5칸 + 플레이어 B 5칸 = 팀 최대 10종.
- 각자 개인 보급, 개인 보급소, 개인 생산 쿨다운.
- 기지 HP, 승패, 전장, 거점 병기는 공유.
- 같은 캐릭터를 두 플레이어가 동시에 가져갈 수 있는지는 PvE 협동에서는 허용 후보로 두되 밸런스 테스트 후 확정한다.

### 11.2 협동 난이도 보정

총 덱 종류 수가 솔로 10종과 같기 때문에 적을 2배로 강화하지 않는다.

1차 출발 후보:

- 적 HP: ×1.15~1.30
- 적 공격력: ×1.05~1.15
- 적 거점 HP: ×1.10~1.20

기본적으로 바꾸지 않는 것:

- 이동속도
- 사거리
- 공격주기
- KB
- 웨이브 수
- 적 개체 수
- 스폰 시점
- 패턴/AI

실제 두 사람의 별도 경제가 주는 이득을 측정해 최소한만 보정한다.

### 11.3 보상/진행

- 협동 첫 클리어도 솔로 첫 클리어와 동일한 진행/보상을 인정한다.
- 별도 `솔로 클리어` 기록/업적은 선택적으로 둘 수 있으나 성장 필수 보상으로 강제하지 않는다.
- 협동만 가능한 필수 성장재화를 만들지 않는다.

### 11.4 매칭/재접속

- 친구 초대 + 공개 매칭.
- 재접속 유예 동안 해당 플레이어 상태를 보존한다.
- 장기 이탈 시 임시 AI 인계를 허용할 수 있다.
- 복귀 시 다시 플레이어에게 제어를 넘긴다.

## 12. 친구 기능과 빠른 통신

필수 1차 기능:

- 친구 코드/검색
- 요청/수락/거절
- 친구 목록
- 온라인 상태
- 협동 초대
- 친선 PvP 초대
- 최근 함께 플레이한 사람
- 삭제/차단

자유 텍스트 채팅은 1차 핵심에서 제외한다. 협동 중 빠른 통신/핑을 우선한다.

예시:

- 준비됐어
- 보급 올릴게
- 전열 부탁
- 후열 부탁
- 병기 사용
- 위험
- 좋아

게임 UI 문구는 플레이어용 자연어만 사용하고 내부 상태/ID를 노출하지 않는다.

## 13. PvP 모드

### 13.1 일반전

- 레이팅 변동 없음.
- 실험 덱/가벼운 플레이용.
- 기본적으로 성장 표준화를 사용한다.

### 13.2 랭킹전

- MMR + 티어 + 전체/상위 순위표.
- 보상: 골드, 모집재화, +재화, 진화재료, 프로필 테두리/칭호 등.
- PvP 전용 필수 성장재료는 두지 않는다.
- 시즌 상위 보상은 장식/명예 비중을 높여 강자가 더 강해지는 폭주를 막는다.

### 13.3 친선전

- 친구 초대/방 코드.
- 레이팅/보상 없음.
- 표준 성장/실성장, 맵, 일부 규칙을 선택 가능하게 할 수 있다.

### 13.4 1차 우선순위

- 1v1 일반
- 1v1 랭킹
- 2v2 일반
- 2v2 친선
- 2v2 랭킹은 동접 규모 확인 후 업데이트 가능

랭킹전에서는 Lv/+Lv/메인 영구 보너스 등 장기 육성 수치를 표준화하되 보유 캐릭터와 해금 형태의 수집 의미는 유지한다.

## 14. 스테이지 데이터 최소 필드

장기적으로 스테이지 데이터는 최소 다음을 데이터로 가져야 한다.

- id / collectionId / chapterId
- name / subtitle
- stageKind
- difficulty 1~12
- multiplayerPolicy
- mapLength / theme / decorSeed
- playerBaseHp / enemyBaseHp
- startingSupply
- playerUnitCap / enemyUnitCap
- waves / trigger DSL
- rewards / firstClearRewards / repeatRewards
- permanentBonus
- speedUpEligibility
- sweepEligibility
- rewardChargePolicy
- formationRestrictions
- specialRules
- coopStatScaling
- unlocks

스테이지별 특수 로직을 BattleScene/UI에서 직접 하드코딩하지 않는다.

---

## 15. 스폰/특수 규칙 DSL

지원 목표 트리거:

- 특정 tick/시간
- 적 거점 HP 비율
- 아군 거점 HP 비율
- 특정 적 사망
- 누적 처치/사망
- 특정 페이즈 완료
- AND/OR 복합 조건

특수 규칙은 자유 문자열 patch가 아니라 등록된 rule ID와 schema를 사용한다.

---

## 16. 설계/검증 절차

각 스테이지는 콘텐츠 위키에 다음을 기록한 후 구현한다.

- 설계 상태: DESIGN_TARGET / TESTED / LOCKED
- 목적/학습 요소
- 적 구성과 스폰
- 경제
- 권장 성장
- 난이도 산정 근거
- 솔로/협동 정책
- 협동 배율
- 첫/반복 보상
- 예상 클리어 시간
- 플레이테스트 메모

스테이지가 재미없거나 지나치게 쉽고 어려우면 구현을 기획에 억지로 맞추지 않고 위키/JSON/테스트를 함께 수정한다.
