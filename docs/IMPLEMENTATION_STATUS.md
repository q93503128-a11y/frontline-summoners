# 구현 상태

이 문서는 `docs/CANONICAL.md`를 대체하지 않는다. 매 작업 전 정본을 먼저 읽고, 상세 방향은 `docs/GAME_DESIGN_FULL.md`와 대조한다.

## 2026-08-24 — campaign vertical slice 0.0.17

### 문서 체계

- `docs/CANONICAL.md`: 현재 v0.30. 최신 핵심 결정 정본.
- `docs/GAME_DESIGN_FULL.md`: 통합 전체 기획서. 전투/경제/수집/성장/진화/맵/멀티/서버/로드맵까지 상세 보존.
- `docs/IMPLEMENTATION_STATUS.md`: 이 파일. 현재 구현/미구현 구분.
- `docs/DEVELOPMENT_RULES.md`: 레거시 덧씌우기 금지, 중복 구현/핫픽스/죽은 분기 즉시 정리 원칙.
- `docs/INDEX.md`: 문서 권위와 읽는 순서.
- `docs/NEW_CHAT_PROMPT.md`: 새 채팅 인수인계용. 새 채팅에서는 이 파일만 믿지 말고 GitHub `main`을 다시 읽어야 한다.
- 구체 콘텐츠 수치는 `content/` JSON이 우선한다.

### 전투 코어

- 공유 `packages/sim` 30Hz 결정적 전투 코어 사용.
- 이동/탐지/선딜/hitFrame/후딜/동시피해/자연 KB/ForcedDisplacement/DYING/거점 승패/stateHash 구현.
- 보급, 보급소 Lv1~8, 생산비, 재생산 쿨다운, 적 웨이브, 처치 보급, 거점 병기 구현.
- 전선포: 적 전체 90 피해 후 자연 KB/사망 판정, 남은 적 60거리/10F 강제 후퇴, 900F 재충전.

### 솔로 일시정지

- 전투 HUD `일시정지` 버튼 구현.
- PC `P`, `ESC` 지원.
- 수동 일시정지 중 simulation update 자체를 막아 tick/보급/쿨다운/적 스폰/이동/공격/투사체 진행 정지.
- Phaser tween도 pause/resume.
- 일시정지 중 소환/보급소/전선포 입력 차단.
- 모달 배경 입력 차단.
- 모바일 세로 가독성 가드 중에도 simulation 정지.
- 멀티의 개별 사용자 pause는 구현 대상이 아님.

### 제1장 경제/전투 템포 재설계

- 이전 ST1 `시작 520 / Lv1 65초당 / 지갑 3000` 폐기.
- 현재 기본 보급소: Lv1 `12/s·1000` → Lv2 `20/s·1400` → Lv3 `30/s·1900` → Lv4 `42/s·2500` → Lv5 `56/s·3200` → Lv6 `72/s·4000` → Lv7 `90/s·5000` → Lv8 `110/s·6200`.
- 강화비: 160 / 260 / 390 / 560 / 760 / 1000 / 1300.
- Lv1 희소성은 유지하되 Lv2 이상 수입 증가폭을 키워 보급소 강화가 실제 투자 가치가 있도록 재조정.
- 시작 보급은 ST1~7 50→110, ST8 160 이후 단계적으로 증가하여 ST19 280 / ST20 300. 정확한 값은 `content/stages/chapter-01.json` 우선.
- ST1 아군/적 거점 900/800. ST20 4000/7200.
- 징집병 이속 6→3, 첫 일반 적 5→2, 돌격병 9→4. 나머지도 역할을 보존하면서 하향.
- 적 처치 보급은 초반 스노우볼을 막되 저보급 환경에서 전투가 정체되지 않도록 적 역할별로 재조정.
- Lv1 최대 보급 1000보다 비싼 왕실기사/이단주술사는 보급소 업그레이드가 필요.
- ST1 테스트는 징집병 한 기 생산 후 시작 보급이 0이 되고 즉시 두 번째 생산이 막히는지 검사.
- deterministic 캠페인 baseline은 로스터 순환 + 압박 시 즉시 가능한 최강 증원 + 단계적 보급소 투자를 사용한다. ST8 이후에는 강화비를 내고도 최소 병력 한 기 비용이 남을 때 첫 보급소 선투자를 허용하며, 이후 추가 강화는 실제 배치 수와 경쟁한다.
- 구경제 시절 과밀 웨이브를 3차로 재배치했다. ST3·4·5·8·10·11·12는 앞선 후보 검증에서 승리권 회복을 확인했고, ST9·13~20은 최종 3차 수치가 `main`에 반영되어 전체 회귀 재검증 대상이다.
- 실제 npm 환경에서 생성된 정식 `package-lock.json`을 커밋했으며 임의 integrity 값은 사용하지 않는다.

### 캐릭터 / 진행

- 신규 계정: 징집병 1종 + STAGE 1만 개방.
- 제1장 캐릭터 합류: ST1 방벽기사 → ST2 수렵창병 → ST4 결투검사 → ST6 청창대 → ST8 전투마도사 → ST10 화염술사 → ST13 왕실기사 → ST16 이단주술사 → ST20 공허현자.
- **현재 10종은 전체 게임 캐릭터 상한이 아니라 기본/핵심 로스터.**
- 기본 로스터는 약 10종으로 충분하며 이후 모집/뽑기, 스테이지/보스 첫 클리어, 외전, 이벤트, 도전 콘텐츠 등으로 캐릭터 풀을 확장한다.
- 현재 10종 이하 단계는 보유 캐릭터 자동 편성. 풀 확장 이후 10칸 수동 편성 본격화.

### 캐릭터 시각 식별성

- 신규 캐릭터는 작은 전투 화면에서 이름/색 없이 실루엣으로 식별 가능한 것을 목표로 한다.
- 종족, 체형, 키, 머리/몸 비율, 장비 부피, 대표 소품, 이동 방식, 공격 자세를 적극적으로 다르게 한다.
- 비슷한 인간형 캐릭터를 색만 바꿔 대량 생산하는 방식은 최종 아트 정책에서 금지.
- 현재 LuizMelo 7개 패밀리는 프로토타입 개발 에셋이며 장기 캐릭터 풀의 최종 다양성 기준이 아니다.

### 캐릭터 업그레이드 / 진화 — 아직 본격 미구현

- 캐릭터 자체 레벨/강화/진화는 핵심 메타 시스템으로 정본에 고정되었으나 현재 전투 vertical slice에는 아직 본격 연결되지 않았다.
- 레벨은 Lv1~50 후보. HP/공격 중심 완만 성장, 정체성 스탯은 기본적으로 유지.
- 진화는 단순 숫자 상승/색놀이가 아니다.
- 진화 시 외형 실루엣, 의상/장비, Idle/Run/Attack 등 모션, 공격 VFX/투사체, 그리고 필요 시 사거리/공격 방식/특효/상태효과/비용/재생산까지 바뀔 수 있다.
- 진화는 sidegrade/전문화 가능하며 이전 형태 재선택을 허용하는 방향.
- 향후 구현 시 character/form 메타 데이터, 성장 저장, 성장 UI, form별 전투 정의/아트/VFX 검증이 필요.

### 콘텐츠 / 맵

- 플레이어 10종, 일반 적 8종 + 보스2종, 제1장 20스테이지.
- 7개 전장 계열 및 스테이지별 decorSeed/mapLength 차등.
- ST19 황금가면 제단, ST20 황금가면+철문 요새 전용 랜드마크.
- ST19/20 baseline은 실제 보스 등장 전 거점 파괴를 허용하지 않음.

### 아트 / 전투 화면

- LuizMelo CC0 계열 7개 아트 패밀리 Idle/Run/Attack.
- build-time vendoring 후 로컬 `/assets/characters` 사용.
- 아트 패밀리별 `attackContactFrame`과 실제 hitFrame 동기화.
- SLASH / PIERCE / BLUNT / MAGIC / FIRE / VOID 6종 공격 시각 언어.
- 원거리 시각 투사체는 선딜 후반 출발 → hitFrame 도착. 판정은 투사체 충돌이 아니라 30Hz hitFrame.
- accumulator 기반 fractional interpolation.
- 피격/거점피격/소환/그림자 VFX 구현.
- 적 속성 라벨은 보스 항상 표시 + 일반 적 간격 디클러터.

### 보물 / 저장

- 20스테이지 보물 첫 클리어 100% 확정. 보물작/RNG 없음.
- `content/treasures/chapter-01.json` typed modifier가 실제 시작 보급/거점HP/유닛 스탯/재생산/처치보급/지갑 강화비/배치한도 등에 적용.
- 미래 보물 선적용 금지.
- IndexedDB 게스트 진행 + 같은 탭 세션 fallback.
- 영구 저장 실패 시 성공으로 표시하지 않고 `현재 탭에서는 진행 유지` 경고.

### 메타 UI

- 메인 화면, 20스테이지 선택(5개×4페이지), 편성, 결과 화면 구현.
- 실제 도감: 동료 5개×2페이지 / 보물 5개×4페이지.
- 보유/미해금/속성/특효/해금 조건/보물 영구 효과를 실제 진행과 연동.
- 실제 BOSS simulation spawn 시 simulationId당 1회 보스 경고.
- 내부 렌더 1280×720.
- 모바일 세로에서는 가로 회전 안내, 전투는 뒤에서 진행되지 않음.
- 성장/업그레이드/진화 전용 메타 UI는 아직 미구현.

### 자동 회귀

- 신규 저장 = 징집병 1종 / ST1만 개방.
- ST1 시작 보급 50, 거점 900/800, 기본 경제 12/s·1000 상한 검사.
- ST1 한 기 생산 후 즉시 두 번째 생산 불가 검사.
- 아군/적 제1장 이동속도 상한 및 첫 적 역할 속도 검사.
- ST1~20은 실제 시점 캐릭터+보물만 사용.
- 새 경제 baseline은 합법적인 보급소 강화와 압박 시 증원 판단을 실제 수행.
- 캐릭터 해금 순서, 최종 10종 로스터, 보스 실제 등장 검사.
- 자연 KB/ForcedDisplacement/전선포/동시피해/stateHash 결정성 검사.
- 공격 contact frame, 원거리 travel tick/보간, 아트 매핑, 속성 UI/라벨 디클러터 검사.
- 도감/보스경고/모바일 가드/저장 fallback/솔로 pause 소스 배선 검사.
- 정본 문서 4종의 보급소/시작 보급 수치가 실제 코드·콘텐츠와 어긋나지 않는지 회귀 검사 추가.
