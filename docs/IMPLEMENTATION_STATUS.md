이 문서는 `docs/CANONICAL.md`를 대체하지 않는다. 매 작업 전 정본을 먼저 읽는다.

## 2026-08-24 — campaign vertical slice 0.0.15

### 전투 코어
- 공유 `packages/sim` 30Hz 결정적 전투 코어 사용.
- 이동/탐지/선딜/hitFrame/후딜/동시피해/자연 KB/ForcedDisplacement/DYING/거점 승패/stateHash 구현.
- 보급, 보급소 Lv1~8, 생산비, 재생산 쿨다운, 적 웨이브, 처치 보급, 거점 병기 구현.
- 전선포: 적 전체 90 피해 후 자연 KB/사망 판정, 남은 적 60거리/10F 강제 후퇴, 900F 재충전.

### 솔로 일시정지
- 전투 HUD `일시정지` 버튼 구현.
- PC `P`, `ESC` 지원.
- 수동 일시정지 중 simulation update 자체를 막아 tick/보급/쿨다운/적 스폰/이동/공격/투사체 진행 정지.
- Phaser tween도 pause/resume.
- 일시정지 중 소환/보급소/전선포 입력 차단.
- 모바일 세로 가독성 가드 중에도 simulation 정지.
- 멀티의 개별 사용자 pause는 구현 대상이 아님.

### 제1장 경제/전투 템포 재설계
- 이전 ST1 `시작 520 / Lv1 65초당 / 지갑 3000`은 초반부터 자원이 과잉이어서 폐기.
- 현재 기본 보급소: Lv1 `12/s·1000` → Lv2 `16/s·1400` → Lv3 `22/s·1900` → Lv4 `29/s·2500` → Lv5 `38/s·3200` → Lv6 `49/s·4000` → Lv7 `62/s·5000` → Lv8 `78/s·6200`.
- 강화비: 160 / 260 / 390 / 560 / 760 / 1000 / 1300.
- ST1 시작 보급 50, 이후 ST20까지 260으로 완만히 증가.
- ST1 아군/적 거점 900/800. ST20 4000/7200까지 단계적으로 증가.
- 징집병 이속 6→3, 첫 일반 적 5→2, 돌격병 9→4. 나머지 아군/적도 역할을 보존하면서 전반 하향.
- 적 처치 보급도 과도한 스노우볼을 막도록 하향.
- Lv1 최대 보급 1000보다 비싼 왕실기사/이단주술사는 보급소 업그레이드가 실제 필요.

### 캐릭터 / 진행
- 신규 계정: 징집병 1종 + STAGE 1만 개방.
- 제1장 캐릭터 합류: ST1 방벽기사 → ST2 수렵창병 → ST4 결투검사 → ST6 청창대 → ST8 전투마도사 → ST10 화염술사 → ST13 왕실기사 → ST16 이단주술사 → ST20 공허현자.
- 현재 10종은 전체 게임 캐릭터 상한이 아니라 **제1장 기본/핵심 로스터**다.
- 이후 모집/외전/보스/이벤트/변칙 계열 등으로 캐릭터 풀을 크게 확장할 예정.
- 현재 10종 이하 단계는 보유 캐릭터 자동 편성. 풀 확장 이후 10칸 수동 편성 본격화.

### 콘텐츠 / 맵
- 플레이어 10종, 일반 적 8종 + 보스2종, 제1장 20스테이지.
- 7개 전장 계열 및 스테이지별 decorSeed/mapLength 차등.
- ST19 황금가면 제단, ST20 황금가면+철문 요새 전용 랜드마크.
- ST19/20 baseline은 실제 보스 등장 전 거점 파괴를 허용하지 않음.

### 아트 / 전투 화면
- LuizMelo CC0 계열 7개 아트 패밀리 Idle/Run/Attack.
- build-time vendoring 후 로컬 `/assets/characters` 사용.
- 아트 패밀리별 `attackContactFrame`과 실제 hitFrame 동기화.
- SLASH / PIERCE / BLUNT / MAGIC / FIRE / VOID 6종 공격 시각 언어.
- 원거리 시각 투사체는 선딜 후반 출발 → hitFrame 도착. 판정은 투사체 충돌이 아니라 30Hz hitFrame.
- accumulator 기반 fractional interpolation으로 60fps 이상 렌더에서 투사체 이동 보간.
- 피격/거점피격/소환/그림자 VFX 구현.
- 적 속성 라벨은 보스 항상 표시 + 일반 적 간격 디클러터.

### 보물 / 저장
- 20스테이지 보물 첫 클리어 100% 확정. 보물작/RNG 없음.
- `content/treasures/chapter-01.json` typed modifier가 실제 시작 보급/거점HP/유닛 스탯/재생산/처치보급/지갑 강화비/배치한도 등에 적용.
- 미래 보물 선적용 금지.
- IndexedDB 게스트 진행 + 같은 탭 세션 fallback.
- 영구 저장 실패 시 성공으로 표시하지 않고 `현재 탭에서는 진행 유지` 경고.

### 메타 UI
- 메인 화면, 20스테이지 선택(5개×4페이지), 편성, 결과 화면 구현.
- 실제 도감 구현: 동료 5개×2페이지 / 보물 5개×4페이지.
- 보유/미해금/속성/특효/해금 조건/보물 영구 효과를 실제 진행과 연동.
- 실제 BOSS simulation spawn 시 simulationId당 1회 보스 경고.
- 내부 렌더 1280×720, 핵심 HUD/거점HP/소환비/쿨다운 글씨 가독성 상향.
- 모바일 세로에서는 가로 회전 안내, 전투는 뒤에서 진행되지 않음.

### 자동 회귀
- 신규 저장 = 징집병 1종 / ST1만 개방.
- ST1 시작 보급 50, 거점 900/800, 기본 경제 12/s·1000 상한 검사.
- ST1은 징집병 1기 생산 후 즉시 두 번째 생산 불가를 검사.
- 아군/적 제1장 이동속도 상한 및 첫 적 역할 속도 검사.
- ST1~20은 실제 시점 캐릭터+보물만 사용.
- 새 경제 baseline은 ST8부터 Lv2, ST17부터 Lv3을 저축/강화하는 deterministic 정책 사용.
- 캐릭터 해금 순서, 최종 10종 로스터, 보스 실제 등장 검사.
- 자연 KB/ForcedDisplacement/전선포/동시피해/stateHash 결정성 검사.
- 공격 contact frame, 원거리 travel tick/보간, 아트 매핑, 속성 UI/라벨 디클러터 검사.
- 도감/보스경고/모바일 가드/저장 fallback/솔로 pause 소스 배선 검사.

## 첫 사용자 테스트 전 남은 주요 항목

1. **새 경제/이속/거점 HP 수치로 ST1~20 실제 baseline이 모두 통과하는지 실행 검증.** 현재 연결 환경에서는 npm/GitHub DNS 때문에 로컬 전체 실행을 재현하지 못해 수동 소스 감사와 회귀 테스트 코드 갱신까지 완료한 상태.
2. 최신 GitHub Actions 및 Cloudflare Pages 실제 배포 성공 여부 확인. 상태 API가 비어 있으면 성공으로 간주하지 않는다.
3. 정본상 필요한 실제 `package-lock.json` 생성/커밋. 무결성 값을 임의 생성하지 않는다.
4. 7개 맵에서 캐릭터 발 위치/그림자/거점 상대 크기 실화면 감사.
5. 새 느린 이동속도에서 장거리 맵이 지나치게 늘어지지 않는지, 새 낮은 경제가 단순 대기게임이 되지 않는지 실제 플레이 감각 감사.
6. 일시정지 모달 입력 차단과 모바일 가로 화면에서 버튼 크기 최종 확인.
7. 첫 수동 테스트 게이트 전체 확인 후에만 사용자에게 Pages 실플레이 요청.
