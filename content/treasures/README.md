# 제1장 보물 데이터

`chapter-01.json`은 제1장 스테이지 첫 클리어 보물의 **실제 영구 효과 정본**이다.

- 스테이지 JSON은 보물의 `id / name / effect`와 획득 위치를 담당한다.
- 이 폴더의 JSON은 같은 `id`가 실제 전투 설정을 어떻게 수정하는지 담당한다.
- 보물은 첫 클리어 100% 확정 획득이며 등급/드랍 확률이 없다.
- 실제 플레이에서는 IndexedDB에 저장된 `treasureIds`만 적용한다. 미래 스테이지 보물 선적용은 금지한다.
- 20개 스테이지 보물 ID와 20개 modifier ID는 정확히 1:1이어야 한다.

현재 modifier 계열:

- 시작 보급 퍼센트
- 아군 거점 최대 HP 퍼센트
- 아군 배치 한도 flat
- 보급소 강화비 퍼센트
- 적 처치 보급 퍼센트
- 유닛 HP/공격/사거리 퍼센트
- 작은 정수 스탯의 정확한 flat 증감(이동속도, 재생산 프레임, 자연 KB 프레임)
- 제1장 완료 플래그

작은 정수 스탯에 `+1%`, `-1%`처럼 실제 체감과 맞지 않는 문구를 쓰지 않는다. 이런 값은 `UNIT_STAT_FLAT`으로 명시한다.
