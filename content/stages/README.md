# 스테이지 콘텐츠 데이터

`chapter-01.json`은 제1장 20스테이지의 데이터 정본 후보입니다.

현재 브라우저 프로토타입은 `apps/client/src/prototype.ts`의 동일 데이터 구조를 사용하고 있으며, CI의 `apps/client/test/progression.test.ts`가 JSON과 런타임 정의의 완전 일치를 검사합니다. 다음 데이터 마이그레이션 패스에서 런타임도 이 JSON을 직접 읽도록 전환합니다.

검증 항목:

- 스테이지 ID / 보물 ID 중복 금지
- 적 ID와 캐릭터 해금 ID 참조 유효성
- 난이도 1~5
- 양쪽 거점 HP / 전장 길이 / 웨이브 수치 범위
- 웨이브 시작 틱 오름차순
- 제1장 20스테이지 고정
- 최소 7개 전장 테마 사용
- 기본캐 `militia`를 보상으로 다시 해금하는 오류 금지
- 동일 캐릭터를 여러 스테이지에서 중복 해금하는 오류 금지
- 같은 테마 + 같은 전장 길이를 연속 재사용하는 단순 복붙 금지

보물은 각 스테이지 첫 클리어 시 100% 확정 획득하며, 캐릭터 해금 보상과 별도입니다.
