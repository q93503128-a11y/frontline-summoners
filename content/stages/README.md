# 스테이지 콘텐츠 데이터

`chapter-01.json`은 제1장 20스테이지의 **런타임 정본**이다.

현재 브라우저와 전투 프로토타입은 `apps/client/src/prototype.ts`에서 이 JSON을 직접 읽고 `@frontline/content-schema` 검증을 통과한 데이터만 사용한다. 같은 스테이지 수치를 TypeScript 배열에 다시 복제하지 않는다.

각 스테이지는 다음을 가진다.

- 실제 전투 길이 `mapLength`
- 플레이어/적 거점 HP
- 시작 보급
- 전장 테마와 `decorSeed`
- 적 웨이브와 등장 틱
- 첫 클리어 100% 확정 보물
- 필요한 경우 첫 클리어 캐릭터 해금

검증 항목:

- 스테이지 ID / 보물 ID 중복 금지
- 적 ID와 캐릭터 해금 ID 참조 유효성
- 난이도 1~5
- 양쪽 거점 HP / 전장 길이 / 웨이브 수치 범위
- 웨이브 시작 틱 오름차순
- 제1장 20스테이지 고정
- 최소 7개 전장 테마 사용
- 기본캐 `militia`를 보상으로 다시 해금하는 오류 금지
- 비스타터 9종이 정확히 한 번씩 해금되어야 함
- 같은 테마 + 같은 전장 길이를 연속 재사용하는 단순 복붙 금지

새 계정은 STAGE 1만 열리며 앞 스테이지 클리어로 다음 스테이지가 순차 개방된다. 보물은 첫 클리어 시 100% 확정 획득하고 캐릭터 해금 보상과 별도다.
